# 快手状态、恢复与汇总

任务配置还必须记录`内容来源`和`搜索关键词或空值`。关键词搜索模式按共享的 [关键词搜索与相关度筛选](../../social-media-interact/references/keyword-search.md) 维护搜索结果位置、高/中/低相关和非内容结果计数；本文件中的推荐区域状态与恢复名称相应替换为搜索结果页状态，停止条件以共享搜索规则为准。

## 任务状态

在当前任务上下文中维护结构化状态，不写入磁盘：

- `任务状态`：等待参数、准备中、批次规划完成、推荐区域加载中、打开推荐内容、本批浏览中、内容理解中、等待当前批次统一确认、本批提交互动中、建立批次检查点、等待人工验证、部分完成、任务完成；
- `配置`：唯一平台、六个任务总上限、总批数、当前批次、本批浏览配额和五类互动有效上限；
- `计数`：本批与累计的已浏览、高/中/低置信度，以及五类互动各自的候选/成功/已存在/待确认/用户取消/跳过；
- `推荐列表状态`：标签页、推荐区域、最近处理位置、连续无有效内容次数；
- `内容账本`：稳定作品标识、批次号、类型、置信度、点赞/评论/收藏状态、评论指纹和发送状态、异常和跳过原因；
- `作者账本`：账号标识、来源作品、关注状态和异常；
- `私信账本`：会话标识、对方标识、最近入站消息指纹、回复原文指纹、编辑状态、发送尝试次数和异常。

账本只保存防重复、恢复和汇总所需的最少信息，不保存账号凭据或完整页面内容。

## 终态与幂等

点赞状态：`未操作`、`候选`、`已存在`、`成功`、`待确认`、`用户取消`、`跳过`。评论状态：`未操作`、`候选`、`已存在`、`成功`、`待确认`、`用户取消`、`跳过`。

- `候选`：当前批浏览阶段已选中但尚未提交，等待当前批次统一确认。
- `成功`：页面后置状态明确，只计数一次。
- `已存在`：任务开始前已互动，不重复操作，不计入本任务新增成功数。
- `待确认`：动作可能已经发生，不计为成功，但占用对应上限并禁止重试。
- `用户取消`：当前批次统一确认被拒绝，候选未提交。
- `跳过`：记录原因后继续下一条推荐内容。

任何 timeout 都不直接等于失败。普通打开或返回动作明确未发生时最多重试一次；点赞点击、评论发送或其后置状态不明确时禁止重复点击。

收藏和关注使用终态：`未操作`、`候选`、`已存在`、`成功`、`待确认`、`用户取消`、`跳过`。只允许从明确的未收藏/未关注状态执行一次新增操作；不得执行取消动作。私信回复使用相同终态，并记录发送尝试次数；点击发送后次数必须保持为 `1`。

评论编辑状态依次为：`未展开`、`编辑态已验证`、`文本已核对`、`发送已点击`、`结果已验证`。展开失败、文本不一致或发送控件未启用时不得发送。一旦进入`发送已点击`，发送尝试次数必须保持为 `1`。

## 异常与恢复

### 单条可恢复

推荐卡片无法打开、详情不匹配、视频无法播放、控件无法识别、点赞/收藏列表找不到精确候选、私信会话或编辑框验证失败：记录异常并处理下一项。无法完成基本预览时不增加`已浏览`；已完成浏览但互动异常时保留浏览计数。

点赞或评论点击后结果不明确必须记为`待确认`，不得按普通可恢复异常重试。

### 推荐列表恢复

关闭详情或返回推荐列表后，重新读取推荐区域并使用账本去重。若原位置已失效，按当前可见顺序跳过已处理作品，继续第一个未处理推荐内容，不通过搜索找回作品。

### 暂停等待用户

登录过期、验证码、扫码、安全验证或异常访问验证出现时，立即停止自动互动并改为`等待人工验证`。不得读取验证码、替用户验证或绕过限制。

用户确认完成验证后，重新读取页面，核对当前作品与互动状态，用明确后置状态修正账本，然后从当前进度继续，不清空计数。

### 无法安全继续

Codex 内置浏览器连接不可恢复、推荐内容连续失败达到上限、页面结构无法可靠识别或平台明确限制继续操作时，停止并报告`部分完成`。不换用外部浏览器或 API、不猜测结果、不扩大权限。

## 汇总格式

```text
### 快手互动任务完成 / 部分完成 / 等待人工验证

平台：快手；批次：已完成 N / 共 N 批
任务总上限：浏览 N，点赞 N，评论 N，收藏 N，关注 N，私信回复 N
本批结果：浏览 N，点赞/评论/收藏/关注/私信回复成功 N / N / N / N / N
累计浏览：N 条
高/中/低置信度：N / N / N 条
点赞成功：N 条
点赞待确认：N 条
评论成功：N 条
评论待确认：N 条
收藏成功/待确认：N / N 条
关注成功/待确认：N / N 个账号
私信回复成功/待确认：N / N 个会话
已存在/用户取消候选：N / N 项
跳过互动：N 条
页面异常：N 条
```

每批结束先给出本批结果、累计进度和任务剩余额度；全部批次结束后给出累计合计、未使用上限和主要跳过原因。有异常、待确认或未完成时，补充批次号、作品序号、最少必要原因和是否需要用户操作。不要回显完整评论区、账号信息、Cookie、Token 或无关浏览数据。
