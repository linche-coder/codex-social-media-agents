# 快手推荐内容执行流程

本文件默认描述`内容来源=推荐内容`。选择`关键词搜索`时，以共享的 [关键词搜索与相关度筛选](../../social-media-interact/references/keyword-search.md) 替代本文的推荐区域入口、列表顺序、返回恢复和无新推荐终止规则；本文其余内容理解、候选、确认、提交和核验规则继续适用，文中的“推荐内容/推荐列表”在这些环节视为当前搜索结果内容/搜索结果页。

## 执行阶段

1. `参数与批次校验`：由统一入口传入唯一平台、任务总上限、当前批次配额和任务剩余额度。
2. `浏览与候选筛选`：从推荐区域逐条预览本批内容，筛选不超过本批有效上限的候选，不执行公开互动。
3. `候选交接与调整`：把本批账本交回统一入口，完成跨批评论查重，并允许用户在系统确认前删除候选或修改文本。
4. `当前批次统一确认与提交`：统一入口只请求一次系统确认；确认后立即回到快手提交并验证。
5. `批次检查点`：更新累计账本和任务剩余额度，再进入下一批；只有最后一批检查已有入站私信。

## 1. 准备与入口

1. 读取 `browser:control-in-app-browser` 的完整说明，按其规范加载随附的 `browser-client.mjs`，显式选择 `agent.browsers.get("iab")` 并完整读取内置浏览器文档。若统一入口已建立 `iab` 绑定则直接复用，不重新选择浏览器。
2. 只复用该 `iab` 绑定中已打开的快手普通网页标签页；没有时在同一内置浏览器中新建标签页，打开快手首页并进入推荐内容区域。不得回退到 Chrome、Edge、网页搜索、平台 API 或其他浏览器工具。
3. 确认推荐列表和内容卡片可见、可交互。未登录时停在登录页并报告`等待用户登录`；验证码、扫码、安全验证或异常访问验证按`等待人工验证`处理。
4. 复用统一入口建立的累计任务账本和当前批次检查点，并记录推荐列表标签页、页面位置和已处理内容标识；状态只保留在当前任务，不写入本地文件。

## 2. 打开下一条推荐内容

按当前推荐区域的页面顺序定位下一条未处理内容。优先使用作品 ID 或规范化作品 URL 作为`稳定内容标识`；没有稳定 ID 或规范化 URL 时，可用可见作者、标题或文案组合形成仅用于本次浏览去重的临时标识，但该内容不得进入延后互动候选。

1. 所有定位限制在当前推荐内容区域，不把导航、搜索结果、关注内容或其他页面卡片计入任务。
2. 打开推荐卡片后重新读取页面，核对详情页内容标识与卡片对应，并重新创建播放器、图文区域和互动控件定位器。
3. 已在账本中的内容：关闭详情或返回推荐列表，继续下一条，不增加浏览数。
4. 内容不存在、完全无法加载或卡片与详情标识不一致：记录异常，返回推荐列表，不增加有效浏览数。
5. 每次返回推荐列表都重新读取页面状态；优先恢复到原推荐区域和最近处理位置，再继续下一条。不得复用详情页或返回前取得的元素、定位器和固定坐标。

滚动加载更多内容时，只处理新出现且未在账本中的内容卡片。推荐内容模式不使用搜索补足数量；关键词搜索模式不使用第二个关键词、指定账号或外部链接补足数量。

## 3. 真实预览与内容理解

### 视频内容

确认视频实际播放并观察进度向前推进。按共享视频预览规则使用页面支持的最高倍速，每条实际预览最多 `60` 秒；视频提前结束或已足以理解时可以更早停止，不要求完整播放。结合画面、字幕、文案、标题和话题理解主要表达；达到上限后信息仍不足时可按共享规则只读参考当前视频已有评论，禁止只看封面或推荐卡片标题后立即判断。

播放失败但其他可见信息足以理解时可记为中置信度；信息不足时记为低置信度，不点赞、不评论。

### 图文内容

若推荐内容为图文，应浏览主要图片或轮播页并阅读可见文案。只看首图或封面不算完成浏览；无法理解时记为低置信度。

### 最少内部记录

每条记录：内容类型、主题、主要表达、可见依据、理解置信度、是否广告或信息过少，以及点赞、评论判断和跳过理由。

完成理解后才把`已浏览 +1`，再处理当前内容的点赞和评论候选。

## 4. 点赞候选筛选

仅在`本批点赞候选数 < 本批点赞有效上限`且任务点赞仍有剩余额度时考虑点赞候选。

1. 将定位限制在当前详情内容容器，重新读取内容标识和可见点赞控件。
2. 已点赞时记为`已存在`，不列入候选。
3. 高或中置信度内容确有信息价值、质量、观点或讨论价值时才记为`候选`；低置信度、纯广告、无法理解或明显低质量内容跳过。
4. 浏览阶段不得点击点赞控件；候选达到本批点赞有效上限后继续完成推荐内容浏览，但不再新增点赞候选。

点赞上限不是目标，禁止固定概率、固定间隔或为凑数降低标准。

## 5. 评论候选生成

仅在`本批评论候选数 < 本批评论有效上限`、任务评论仍有剩余额度且内容适合讨论时生成评论：

1. 检查任务账本和当前可见评论，确认本账号没有对该作品提交过评论。
2. 按 [评论生成与审核](comment-policy.md) 生成并审核；第一次不合格时最多重写一次，仍不合格则跳过。
3. 审核通过后保存评论原文和会话内指纹并记为`候选`。浏览阶段不得打开编辑框、填写或发送。
4. 候选达到本批评论有效上限后继续完成浏览，但不再生成评论。

## 6. 收藏、关注与私信回复候选

按 [收藏、关注与私信回复](../../social-media-interact/references/extended-interactions.md) 执行。预览当前作品时独立判断收藏价值和作者持续关注价值，分别按作品 ID 与作者账号 ID 去重；浏览阶段不点击收藏或关注。

只有最后一批达到本批浏览配额后，若`私信回复任务剩余额度 > 0`，才只读进入快手消息入口，按未读优先、最近会话次序检查已有入站私信并生成不超过剩余额度的回复草稿。不得主动给作品作者发私信，也不得在候选阶段输入文本。

## 7. 本批候选交接与统一确认

完成本批浏览配额后，把以下信息交回 `$social-media-interact`：

- 每条点赞候选的最少必要作品标识或主题；
- 每条评论对应的最少必要作品标识或主题；
- 每条拟发布评论的完整文本；
- 收藏候选的作品标识、关注候选的作者标识；
- 私信候选的会话和对方标识、最少必要上下文及完整回复文本；
- 五类互动候选数量、本批有效上限和任务剩余额度；
- 浏览完成度、异常和跳过原因。

快手流程把候选交回统一入口，由统一入口完成跨批查重、用户调整和当前批次的一次系统确认。确认只覆盖本批最终候选和完整文本；确认后不得改写文本或按动作、单条内容重复询问。用户拒绝时把本批候选记为`用户取消`并按统一入口规则结束或显式跳过本批。

## 8. 当前批次确认后的互动提交

只有收到统一入口传回的当前批次确认结果后，才按推荐列表中的原顺序处理本批已展示候选。

按候选原顺序先执行点赞、收藏和关注，再执行评论，最后回复已有入站私信。每项操作都必须重新核对作品、作者或会话标识；已存在则跳过，状态不明则记为`待确认`并禁止重试。私信使用共享规范中的单次发送状态机。

评论候选依次经过`候选 → 编辑态已验证 → 文本已核对 → 发送已点击 → 成功或待确认`：

1. 从推荐列表重新打开候选作品，核对内容标识、账本和页面可见评论；发现本账号评论已存在时记`已存在`并跳过。
2. 所有定位限制在当前作品详情容器和当前评论区域。评论区或输入区未展开时，先点击当前详情内可见且可交互的评论入口。
3. 点击入口后丢弃旧 DOM 快照、元素引用和定位器，重新读取页面，并重新定位当前详情容器、评论区域、真实编辑框和发送控件。
4. 只有内容标识不变，且评论区域中存在可见、可交互、能够获得焦点并接受输入的真实编辑框，才记为`编辑态已验证`。隐藏或仅存在于 DOM 的`contenteditable`元素不能作为成功证据。
5. 展开失败或无法从多个编辑元素中唯一确定当前评论区域内的真实编辑框时，不得输入或发送；记录异常并处理下一候选。
6. 填入当前批次确认时展示的原评论文本。输入后重新读取页面，确认编辑值逐字一致，且发送控件可见、可交互并已启用。
7. 发送前再次核对作品 ID、账本评论原文、编辑值和发送控件状态；任一不一致时不得提交。
8. 最终核对通过后把`评论发送尝试次数`记为 `1`，点击发送一次。无论页面返回、超时或结果如何，同一候选不得再次点击发送。
9. 发送后重新读取页面。只有本账号评论明确出现、页面明确提示成功或其他等价权威状态时记`成功`。
10. 如果意外返回推荐列表、详情或评论区关闭、内容标识变化、页面超时或结果无法确认，记为`待确认`并禁止重试。页面明确拒绝发送时记录异常并继续下一候选，不补发同一评论。

所有定位优先依据可见状态、可交互状态和当前 UI 层级，不使用固定屏幕坐标。

## 9. 评论对象恢复

评论阶段优先用作品 ID 或规范化 URL 重新打开。直接入口失效时，可以从本账号点赞列表或收藏列表恢复，但只能处理与任务账本 ID 精确匹配的候选；不得按标题、作者或封面模糊匹配，也不得处理旧互动内容。连续 5 次加载找不到目标时记为`评论对象不可恢复`并跳过。

评论候选不得仅为定位而自动点赞或收藏；只有它独立满足标准、未超过上限且已在当前批次统一确认中展示时，才允许先完成对应动作再从列表恢复。

## 10. 停止条件

当前批正常浏览结束条件为`本批已浏览 == 本批浏览配额`。连续 5 次无法获得新的有效推荐内容时，刷新推荐区域或重新进入推荐页一次；恢复后仍连续 5 次失败则以`部分完成，推荐内容无法继续`停止并汇总，不得无限重试。

本批候选提交完成、用户拒绝当前批次统一确认或本批没有候选时，把结果和检查点交回统一入口。仅当全部批次完成或安全停止条件成立时结束整个任务；不得回到旧批次补数。
