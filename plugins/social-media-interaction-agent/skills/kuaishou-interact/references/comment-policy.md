# 快手评论生成与审核

## 评论候选标准

仅在已实际打开并预览本任务内容、能够准确理解主要表达时生成评论。关键词搜索内容还必须满足共享相关度规则：

- 高置信度：可以评论。
- 中置信度：评论不依赖缺失信息时谨慎评论，否则跳过。
- 低置信度：不评论。

纯广告、信息过少、只有画面展示但没有明确讨论点、页面异常或观点无法确定时默认跳过。

## 普通网友风格

评论一般为 15～50 个中文字，简短、自然、口语化，并与画面、字幕或文案中的具体内容直接相关。可以赞同、补充、提问、质疑或温和表达不同意见，不设置固定比例。

禁止：

- 编造用户身份、职业、地区或个人经历；
- 营销、引流、联系方式或号召关注；
- 复制标题、机械复述文案或使用无关模板；
- 辱骂、讽刺、挑衅、攻击作者或群体；
- 冒充客服、媒体、专家，或把无法核实的信息写成事实；
- 与当前批或此前批次评论重复或高度相似的句式；相同开头、相同句式骨架、只替换少量名词或语义基本相同都视为高度相似。

## 发送前审核

每条评论候选检查：是否基于实际预览、是否具体相关、是否与其他候选重复、是否自然简短、是否包含营销或虚假经历、是否包含攻击或未经证实的事实，以及是否适合由普通网友公开发布。

第一次不合格时最多重写一次，重写后必须重新执行跨批次查重；第二次仍不合格或无法确认安全相关时跳过，不为达到评论上限强行生成，也不得删除旧评论指纹来规避查重。
