# 关键词搜索与相关度筛选

本规则只在`内容来源=关键词搜索`时读取。它覆盖各平台工作流中仅针对首页推荐流的入口、列表来源和列表恢复规则；内容理解、候选筛选、确认、提交、核验和停止条件仍按对应平台工作流执行。

## 输入边界

- 一次任务只允许一个由用户提供的关键词或短语，去除首尾空白后必须为非空单行文本，最长 `50` 个字符。
- 原样使用用户确认的关键词，不自动改写、拆分、翻译、扩展同义词，也不点击联想词、相关搜索、热搜或话题建议。
- 固定使用平台默认综合排序。若页面明确显示其他排序已被选中，可在能够可靠识别时切回`综合`或平台等价默认项一次；无法判断时保留平台默认状态并在结果中说明，不尝试多个排序。
- 关键词只决定内容来源，不授权搜索指定账号、访问站外链接、主动私信或扩大互动范围。

## 搜索入口

1. 复用当前任务的同一个 Codex 内置浏览器和目标平台普通网页标签页；没有对应标签页时，在同一内置浏览器中打开平台首页。
2. 通过平台网页端可见搜索入口输入已确认关键词并提交。不得使用网页搜索引擎、平台 API、外部浏览器或直接拼接未经页面验证的隐藏接口。
3. 提交后重新读取页面，核对搜索框或页面标题中的关键词与任务账本完全一致，并确认结果区域属于当前平台。
4. 未登录、出现验证码、扫码或安全验证时暂停等待用户。搜索入口不存在、网页端不支持、结果页无法可靠识别或关键词无法核对时，以`部分完成`停止，不切换其他来源补足。

## 结果范围与顺序

按当前默认综合结果的页面顺序处理，只把能够打开并形成稳定内容标识的视频、图文、笔记、微博或动态视为任务内容。

- 账号卡片、话题页、榜单、直播间、商品卡、纯广告卡、搜索建议和站外结果只记为`非内容结果`，不计入浏览数量，也不生成互动候选。
- 同一内容的重复结果按稳定内容 ID 或规范化 URL 跳过，不增加浏览数。
- 打开结果后必须核对详情与搜索结果卡片属于同一对象；无法核对时记录异常并返回结果页。
- 实际播放视频或浏览主要图文和正文、达到平台工作流的理解要求后，才计入浏览数量。
- 每次返回搜索结果页都重新读取页面，不复用旧元素、旧定位器或固定坐标。

## 相关度判断

每条完成浏览的内容根据标题、正文、画面、字幕、话题和必要上下文判断与搜索关键词的关系，并在账本中记录：

- `高相关`：核心主题直接围绕关键词，可按正常标准生成点赞、评论、收藏和关注候选；
- `中相关`：关键词是明确的重要组成部分但不是核心主题，可以生成点赞或收藏候选；只有评论能够直接落到可见具体内容时才允许评论，关注仍需具备持续价值；
- `低相关`：仅偶然提及、歧义命中、标题诱导或实际主题无关，只计入已浏览和低相关统计，不生成任何互动候选。

不得仅凭关键词出现在标题、标签或字幕中就判为高相关。评论必须回应实际内容，不得把关键词机械拼接到通用模板中。无法稳定判断相关度时按`低相关`处理。

## 账本、恢复与停止

任务配置和每个批次检查点额外记录：`内容来源=关键词搜索`、原始关键词、当前排序状态、最近搜索结果位置、已检查结果数以及高/中/低相关和非内容结果计数。

返回结果页后先核对关键词未变化，再按账本跳过已处理内容并继续第一个未处理结果。结果页丢失时，只允许从平台可见搜索入口重新提交同一关键词一次；不得改用相似词、推荐流、历史记录、点赞列表或收藏列表来补足浏览数量。已确认互动对象的恢复仍优先使用稳定内容 ID 或规范化 URL，并按平台规则核对。

连续 `10` 个结果均为重复、非内容、无法打开或无法完成理解时，只允许重新提交同一关键词一次；恢复后再次连续 `10` 个无效结果，则以`部分完成，搜索结果无法继续`停止并汇总。平台明确限制搜索或继续操作时立即停止。

## 完成汇总

除通用任务结果外，额外报告：

- 用户关键词与实际排序状态；
- 已检查搜索结果数；
- 实际浏览数；
- 高相关、中相关、低相关数量；
- 重复、非内容、打不开和无法核对的数量；
- 因相关度不足而跳过的各类互动数量或主要原因。
