# 评论生成与审核

## 适合评论的内容

优先考虑有明确观点、问题、争议点、经验分享或讨论空间，且 Agent 已能形成自然、具体回应的内容。关键词搜索内容还必须满足共享相关度规则。

- 高置信度：可以评论。
- 中置信度：仅在评论不依赖缺失信息时谨慎评论，否则跳过。
- 低置信度：不评论。

纯广告、信息过少、单纯风景、纯展示但没有讨论点、页面异常或观点无法确定时默认跳过。

## 普通网友风格

评论一般为 15～50 个中文字，简短、自然、口语化，并与当前内容中的具体观点或细节直接相关。根据内容选择赞同、补充、提问、质疑或温和表达不同意见，不设置固定比例。

争议内容使用“观点 + 简单理由”。可以说“不太认同”“可能还得分情况”，但不得辱骂、讽刺、挑衅、攻击作者或群体，也不得为了互动制造对立。无法核实的信息不要写成事实。

禁止：

- 编造用户身份、职业、地区或个人经历，例如“我家就是这样”“我去年遇到过”；
- 营销、引流、联系方式或号召关注；
- 复制标题、机械复述正文；
- 与内容无关的“说得真好”“支持一下”“666”“感谢分享”等模板灌水；
- 冒充客服、媒体或专家，或使用 AI 总结腔；
- 在同一任务中重复或高度相似的评论句式。

## 发送前内部审核

每条评论发送前逐项检查：

1. 是否基于实际浏览到的内容，而非只基于标题；
2. 是否与当前内容具体相关且没有误解主要表达；
3. 是否与当前批以及此前批次所有已生成、已取消、已成功或待确认的评论重复或高度相似；相同开头、相同句式骨架、只替换少量名词或语义基本相同都视为高度相似；
4. 是否自然、简短、非模板化；
5. 是否包含营销、引流、联系方式或虚假经历；
6. 是否包含辱骂、攻击、挑衅、群体贬损或把猜测写成事实；
7. 是否适合由普通网友公开发布。

第一次不合格时只允许重写一次，重写后必须重新执行跨批次查重。第二次仍不合格，或无法确信安全相关，就跳过该篇评论，不为完成上限强行发布，也不得删除旧评论指纹来规避查重。
