# 状态、恢复与汇总

任务配置还必须记录`内容来源`和`搜索关键词或空值`。关键词搜索模式按共享的 [关键词搜索与相关度筛选](../../social-media-interact/references/keyword-search.md) 维护搜索结果位置、高/中/低相关和非内容结果计数；本文件中的推荐流状态与恢复名称相应替换为搜索结果页状态，停止条件以共享搜索规则为准。

## 任务状态

在当前任务上下文中维护结构化状态，不写入磁盘：

- `任务状态`：准备中、批次规划完成、推荐流加载中、本批浏览中、内容理解中、等待当前批次统一确认、本批提交互动中、建立批次检查点、等待人工验证、部分完成、任务完成；
- `配置`：唯一平台、六个任务总上限、总批数、当前批次、本批浏览配额和五类互动有效上限；
- `计数`：本批与累计的已浏览、高/中/低置信度，以及五类互动各自的候选/成功/已存在/待确认/用户取消/跳过；
- `当前批次`、`当前序号`、`任务剩余额度`与`连续无有效内容次数`；
- `内容账本`：稳定内容标识、批次号、类型、置信度、点赞/评论/收藏状态、评论指纹和发送状态、异常和跳过原因；
- `作者账本`：账号标识、来源内容、关注状态和异常；
- `私信账本`：会话标识、对方标识、最近入站消息指纹、回复原文指纹、编辑状态、发送尝试次数和异常。

账本只保留防重复、恢复和汇总需要的最少信息，不保存账号凭据或完整页面内容。

## 单篇终态与幂等

点赞状态使用：`未操作`、`候选`、`已存在`、`成功`、`待确认`、`用户取消`、`跳过`。评论状态使用：`未操作`、`候选`、`已存在`、`成功`、`待确认`、`用户取消`、`跳过`。

- `候选`：当前批浏览阶段已选中但尚未提交，等待当前批次统一确认。
- `成功`：页面后置状态明确，只计数一次。
- `已存在`：任务前已互动，不重复操作，不计入本任务新增成功数。
- `待确认`：动作可能已经发生，不允许重试，也不把它算作成功；评论待确认占用评论上限。
- `用户取消`：当前批次统一确认被拒绝，候选未提交。
- `跳过`：记录原因后进入下一篇。

任何 timeout 都不直接等于失败。先重新读取页面后置状态；普通导航或打开动作明确未发生时最多重试一次。点赞、评论提交或页面状态不明确时禁止重复点击。

收藏和关注使用同一组终态：`未操作`、`候选`、`已存在`、`成功`、`待确认`、`用户取消`、`跳过`。只允许从明确的未收藏/未关注状态执行一次新增操作；不得执行取消动作。私信回复也使用这些终态，并额外记录`发送尝试次数`，一旦点击发送必须保持为 `1`。

评论编辑状态只用于控制提交过程，可依次为：`折叠态`、`展开态已验证`、`文本已核对`、`发送已点击`、`结果已验证`。只有当前内容标识不变，且展开区域中的真实编辑框、发送按钮和取消按钮均已重新定位并通过可见、可交互检查，才能从`折叠态`进入`展开态已验证`。

- 展开失败、输入文本不一致或发送按钮未启用：不发送，记录具体异常并处理下一候选。
- 一旦进入`发送已点击`，该内容的`评论发送尝试次数`必须保持为 `1`；成功、明确失败或结果不明都不得再次发送。
- 发送后详情关闭、返回推荐流、内容标识变化或缺少权威成功信号：评论状态改为`待确认`，占用评论上限且禁止重试。

## 异常分类

### 单篇可恢复

页面打不开、视频无法播放、互动控件不可用、评论编辑态展开失败、点赞/收藏列表找不到精确候选、私信会话或编辑框无法可靠识别：记录异常并继续。无法完成基本浏览的内容不增加`已浏览`；任何互动点击或消息发送后结果不明确都必须记为`待确认`，不得重试。

### 暂停等待用户

登录过期、验证码、App 扫码、安全验证或异常访问验证：立即停止所有自动互动，状态改为`等待人工验证`并告诉用户当前进度。不得读取验证码、替用户验证或尝试绕过。

用户确认已处理后：

1. 重新读取当前页面；
2. 核对当前内容标识及点赞、评论的真实状态；
3. 用账本修正明确可确认的状态；
4. 从当前进度继续，不清空计数，不从第一篇重跑。

### 无法安全继续

Codex 内置浏览器连接不可恢复、推荐流连续失败达到流程上限、页面结构无法可靠识别或平台明确限制继续操作：停止并报告`部分完成`，保留所有已确认结果，不猜测、不换用外部浏览器或 API、不扩大权限。

## 汇总格式

完成或停止时使用清晰中文，至少包含：

```text
### 小红书互动任务完成 / 部分完成 / 等待人工验证

平台：小红书；批次：已完成 N / 共 N 批
任务总上限：浏览 N，点赞 N，评论 N，收藏 N，关注 N，私信回复 N
本批结果：浏览 N，点赞/评论/收藏/关注/私信回复成功 N / N / N / N / N
累计浏览：N 篇
高/中/低置信度：N / N / N 篇
点赞成功：N 篇
点赞待确认：N 篇
评论成功：N 篇
评论待确认：N 篇
收藏成功/待确认：N / N 篇
关注成功/待确认：N / N 个账号
私信回复成功/待确认：N / N 个会话
已存在/用户取消候选：N / N 项
跳过互动：N 篇
页面异常：N 篇
```

每批结束先给出本批结果、累计进度和任务剩余额度；全部批次结束后给出累计合计、未使用上限和主要跳过原因。有异常、待确认或未完成时，补充批次号、内容序号、最少必要原因和是否需要用户操作。不要回显完整评论区、账号信息、Cookie/Token 或无关浏览数据。
