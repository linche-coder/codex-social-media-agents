# B站首页推荐执行流程

本文件默认描述`内容来源=推荐内容`。选择`关键词搜索`时，以共享的 [关键词搜索与相关度筛选](../../social-media-interact/references/keyword-search.md) 替代本文的首页推荐入口、列表顺序、返回恢复和无新推荐终止规则；本文其余内容理解、候选、确认、提交和核验规则继续适用，文中的“推荐内容/首页推荐”在这些环节视为当前搜索结果内容/搜索结果页。

## 批次阶段

每批依次执行：参数与批次复核、首页推荐浏览与候选筛选、候选交接与用户调整、当前批次一次系统确认、互动提交与验证、批次检查点。只有最后一批检查已有入站私信。

## 1. 准备与入口

1. 按 `browser:control-in-app-browser` 规范复用统一入口建立的 `iab` 绑定；没有 B站普通网页标签页时，在同一内置浏览器中新建标签页并进入 B站首页推荐区域。
2. 不使用 Chrome、Edge、网页搜索、平台 API 或其他浏览器工具。未登录时报告`等待用户登录`；验证码、扫码和安全验证等待用户手动处理。
3. 复用累计账本和当前批次检查点，不写入本地文件。

## 2. 获取下一条唯一推荐内容

按首页推荐顺序打开下一条未处理内容。优先使用 BV/AV 号、稳定动态 ID 或规范化内容 URL 作为稳定标识。没有这些标识时，可以用可见标题与 UP 主形成仅用于本次浏览去重的临时标识，但不得生成延后互动候选。

- 已在累计账本中的内容：跳过，不增加浏览数；
- 内容不存在、打开报错或推荐卡片与详情标识不一致：记录异常，不增加有效浏览数；
- 返回首页后重新读取推荐区域，不复用旧元素、旧定位器或固定坐标；
- 推荐内容模式不使用搜索、排行榜或热门页补足数量；关键词搜索模式不使用第二个关键词、指定 UP 主或外部链接补足数量。

## 3. 真实预览与理解

视频必须确认实际播放且进度向前，按共享视频预览规则使用页面支持的最高倍速，每条实际预览最多 `60` 秒；视频提前结束或已足以理解时可以更早停止，不要求完整播放。结合画面、字幕、简介、标题和分区信息理解主要表达；达到上限后信息仍不足时可按共享规则只读参考当前视频已有评论。只看封面或标题不算有效浏览。图文或动态需要浏览主要图片、正文和必要的展开内容。

记录内容类型、主题、主要表达、可见依据、理解置信度、广告或信息不足情况、互动价值和跳过原因。完成理解后才把本批已浏览加一。

## 4. 候选筛选

候选必须有稳定内容或作者标识，并同时受本批计划配额、单批上限、任务剩余额度和本批浏览数量约束。

- 点赞：明确未点赞，且内容有信息、创作或讨论价值时列为候选；不点击。
- 评论：确认本账号没有已有顶层评论，按 [评论生成与审核](comment-policy.md) 生成并保存文本指纹；不展开输入框、不填写。
- 收藏：明确未收藏且确有复看价值时列为候选。若必须选择收藏夹，只读打开收藏界面识别现有收藏夹，不提交；候选必须记录一个明确现有收藏夹名称，无法唯一确定时跳过。
- 关注：作者稳定身份明确、当前未关注且具有持续关注价值时列为候选；不点击。
- 私信：只有最后一批按共享规则检查已有入站会话，不主动联系 UP 主。

不得使用“一键三连”，不得把投币、充电、弹幕、转发或分享作为候选。

## 5. 本批确认与提交

达到本批浏览配额后，把确切内容/作者/会话标识、收藏夹名称、完整评论或私信文本、候选数量、本批有效上限、任务剩余额度和异常交回 `$social-media-interact`。统一入口完成跨批评论查重和用户调整后，对最终清单只请求一次系统确认。

确认后按点赞、收藏、关注、评论、私信回复顺序处理。每项动作前重新打开并核对稳定标识、真实状态和已确认原文；已存在则记录，状态不明则`待确认`。

### 评论提交

1. 用 BV/AV 号、稳定动态 ID 或规范化 URL 重新打开候选并核对本账号没有已有评论。
2. 在当前内容评论区域内展开输入区；展开后丢弃旧页面快照和定位器，重新定位可见、可交互且能接受输入的真实编辑框和发送控件。
3. 填入当前批次确认的原评论，重新读取并逐字核对编辑值、内容标识和发送控件状态。
4. 最终核对通过后把发送尝试次数记为 `1`，只点击一次。只有本账号评论明确出现、页面明确提示成功或等价权威信号才记为成功；结果不明时记为`待确认`并禁止重试。

### 收藏提交

收藏候选只有在内容标识、未收藏状态和确认清单中的现有收藏夹名称都一致时才提交一次。不得创建收藏夹、改名或临时选择其他收藏夹。提交结果不明时记为`待确认`。

## 6. 精确恢复与停止

互动阶段优先使用稳定内容 ID 或规范化 URL。直接入口失效时，仅在页面提供本账号点赞或收藏列表且能与任务账本 ID 精确匹配时恢复；不得按标题、UP 主或封面模糊匹配。连续 5 次仍找不到目标时跳过。

当前批完成、没有候选或用户拒绝确认时，把结果和检查点交回统一入口。连续 5 次无法获得新有效推荐内容时只允许刷新首页推荐区域一次；仍失败则部分完成并停止。不得回旧批次补数或无限重试。
