# B站评论生成与审核

## 评论候选标准

仅在已实际播放或浏览本任务内容、能够准确理解主要表达时生成顶层评论：高置信度可以评论；中置信度仅在评论不依赖缺失信息时谨慎评论；低置信度不评论。关键词搜索内容还必须满足共享相关度规则。纯广告、信息过少、页面异常或观点无法确定时跳过。

## 普通观众风格

评论一般为 15～60 个中文字，简短、自然，并与视频画面、字幕、简介或正文中的具体内容直接相关。可以赞同、补充、提问或温和表达不同意见，但不得：

- 编造观看经历、身份、职业、地区或与 UP 主的关系；
- 复制标题、机械复述简介、刷梗、求置顶或使用无关模板；
- 营销、引流、联系方式或号召关注；
- 辱骂、挑衅、群体攻击，或把无法核实的信息写成事实；
- 冒充 UP 主、客服、媒体或专家；
- 与当前批或此前批次评论使用相同开头、相同句式骨架、只替换少量名词或表达基本相同语义。

## 发送前审核

检查评论是否基于真实浏览、是否具体相关、是否与全任务评论高度相似、是否自然简短、是否含营销或虚假经历、是否含攻击或未经证实的事实，以及是否适合普通观众公开发布。

第一次不合格时最多重写一次，并重新执行跨批查重；第二次仍不合格时跳过，不为达到上限强行生成，不删除旧评论指纹规避查重。
