# 微博评论生成与审核

## 评论候选标准

仅在已实际阅读、浏览或播放本任务微博并能准确理解主要表达时生成顶层评论。关键词搜索内容还必须满足共享相关度规则。高置信度可以评论；中置信度仅在评论不依赖缺失上下文时谨慎评论；低置信度不评论。广告、抽奖、信息过少、上下文不完整、页面异常或观点无法确定时默认跳过。

## 普通网友风格

评论一般为 10～60 个中文字，简短、自然，并与微博正文、图片或视频中的具体内容直接相关。可以赞同、补充、提问或温和表达不同意见，但不得：

- 编造身份、职业、地区、经历或与博主的关系；
- 复制正文、堆叠话题标签、刷热评话术或使用无关模板；
- 营销、引流、联系方式或号召关注；
- 辱骂、挑衅、群体攻击，或传播未经核实的事实；
- 冒充博主、客服、媒体、机构或专家；
- 与当前批或此前批次评论使用相同开头、相同句式骨架、只替换少量名词或表达基本相同语义。

敏感公共事件、医疗、法律、金融和安全相关内容在事实与上下文不足时不评论，不作专业判断或行动建议。

## 发送前审核

检查评论是否基于真实浏览、是否具体相关、是否与全任务评论高度相似、是否自然简短、是否含营销或虚假经历、是否含攻击或未经证实的事实，以及是否适合普通网友公开发布。

第一次不合格时最多重写一次，并重新执行跨批查重；第二次仍不合格时跳过，不为达到上限强行生成，不删除旧评论指纹规避查重。
