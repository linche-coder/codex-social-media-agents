# 每个内容项三条话题

话题支持用户手动输入和AI生成，默认使用AI生成。每条视频或每篇图文最终必须使用恰好三条完整话题；话题在所有目标平台保持相同语义，再映射到各平台真实话题或标签控件。

## 输入判断

- 用户为某个内容项手动填写三条话题：优先使用，去掉开头`#`并去重，不擅自换成热门词。
- 用户填写`AI生成`或留空：视频根据标题、简介和可确认内容生成；图文根据整组图片、标题、正文和可确认内容生成。
- 用户提供与视频数量相同的话题组：按顺序一一对应。
- 用户只提供一组话题且未说明整批共用：不要默认复制给所有内容项，其余内容使用AI生成。

## AI 生成规则

1. 结合标题、简介和可确认的视频内容识别核心对象、内容主题和具体场景。
2. 第一条优先使用核心主题，第二条使用细分场景，第三条使用直接相关的受众或领域词。
3. 话题使用完整、自然的中文词组；通常不少于两个汉字，禁止生成`农`、`改`、`生`等单字或被截断的前缀。
4. 不添加内容中没有的地点、人物、品牌、热点或夸张结论。
5. 三条话题不得只是同义重复，也不得使用`热门`、`上热门`、`推荐`等空泛词凑数。

例如：标题`农村盖房越来越贵，普通农民还盖得起吗？`，简介`记录农村自建房成本变化和真实生活。`，可生成：`农村生活`、`农村建房`、`自建房成本`。

## 页面写入与验证

- 按各平台 workflow 将三条完整话题逐条写入真实话题或标签控件。
- 每条都必须形成平台认可的独立话题、标签卡片、链接或已选项，且页面回显的规范化文本必须与预期完整话题一致；正文中的普通`#文字`不算成功。
- 禁止因为候选列表先出现前缀就点击第一个候选；必须先完成整条话题输入，再选择完整文本精确匹配的候选。
- 平台限制话题数量少于三条时，按相关性顺序填写平台允许的最大数量，并在审批摘要中明确说明；不得伪报三条都已生效。
- 任一话题被截断或没有生效时，先删除错误文本或标签，再从干净状态重试一次；仍失败则停止该内容，不带着错误话题提交。
