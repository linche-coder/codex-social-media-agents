# 快手图文作品流程

目标页：`https://cp.kuaishou.com/article/publish/video`，选择`上传图文`。2026-09-04在Codex自带浏览器实测该入口可用：最多31张；单个图片最大15MB；支持png、jpg、jpeg、webp，不支持gif、livp；推荐3:4竖图。每次运行仍以页面当前提示为准。

1. 打开目标页并选择`上传图文`，确认登录和空白上传区。
2. 快手可能只保留一条上次未发布内容。多篇任务必须在上传前按内容数量创建独立图文发布标签页并固定绑定，禁止上传一篇后再临时建下一页。
3. 检测到旧内容时沿用删除确认边界；不得自动删除或用旧内容覆盖本次任务。
4. 按 [file-injection.md](file-injection.md) 一次选择当前内容项全部图片，并核对缩略图数量和顺序。
5. 上传后读取真实编辑页。若只有`作品描述`，按`标题 + 换行 + 正文`写入；若存在独立标题框则分别填写，避免重复。
6. 三条话题沿用视频流程的完整词精确匹配规则：完整输入后再选候选，禁止点击单字前缀或第一项；最终逐字核对。
7. 不读取、不选择、不修改作者声明、创作者声明或同类声明。
8. 默认首图为封面；存在独立封面控件时按用户指定设置。
9. 按 [schedule-policy.md](schedule-policy.md) 设置立即或平台原生定时发布；不支持时不得改成立即发布。
10. 准备完成后保留页面进入统一审批。

只有明确成功提示或内容管理中存在对应图文、状态和时间，才能报告成功。
