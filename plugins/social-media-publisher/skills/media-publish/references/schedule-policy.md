# 立即发布与多时间定时发布

时区固定为`Asia/Shanghai`。用户必须选择`立即发布`或`定时发布`；未选择时先询问，不擅自代选。

## 立即发布

- 依旧先完成全部视频上传、字段填写、封面和页面核对。
- 所有可处理内容准备完成后，只请求一次统一发布确认。
- 用户确认后严格按平台与内容顺序逐条点击发布并核验结果。
- 立即发布不填写或保留任何定时时间；页面若残留旧定时状态，先明确关闭并核对。

## 定时发布

定时发布只使用平台原生定时能力。用户可以采用任一方式提供多个发布时间：

### 方式一：逐条时间

按内容顺序填写完整北京时间，例如：

```text
发布时间：
1. 2026-09-05 08:00
2. 2026-09-05 12:00
3. 2026-09-06 09:30
```

时间数量必须与内容项数量一致。少于或多于内容数量时先列出差异并请用户修正，不循环使用、不自行补时间。

### 方式二：开始日期与每日时间点

填写一个开始日期和一个或多个每天重复使用的时间点，例如：

```text
开始日期：2026-09-05
每日时间：08:00、12:00、15:00、17:30
```

内容按顺序使用当天时间点，使用完后自动进入下一天并从第一个时间点继续。每日时间按用户填写顺序使用；若顺序混乱，先按当天先后排序并在上传前展示结果。

## 共同规则

- 同一内容发布到多个平台时使用同一个发布方式和同一个目标时间。
- 生成排期后，在上传前展示内容数量、首条时间和末条时间；逐条时间模式应展示完整映射。
- 定时时间已经过去、不满足平台最小提前量或超出最大预约范围时，不擅自改成其他时间或立即发布；标记具体内容并请用户调整。
- 某个平台不支持原生定时发布时标记`不支持当前定时方案`，其他平台继续。
- 定时作品成功提交后由平台执行，届时电脑可以关闭；不得声称 Codex 会在未来自动打开网页点击发布。

## 核验

立即发布必须确认定时开关已关闭。定时发布必须读取页面回显，确认日期、时刻和北京时间排期一致。最终审批摘要逐条列出`立即发布`或具体目标时间；提交成功后报告平台实际接受的发布方式和时间。
