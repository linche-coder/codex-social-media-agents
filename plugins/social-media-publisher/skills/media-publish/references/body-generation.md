# 图文正文手动输入与AI生成

图文正文支持用户手动填写和AI生成，默认使用AI生成。

- 用户提供正文时原样使用，除平台明确长度限制外不改写。
- 用户填写`AI生成`或留空时，综合该内容项全部图片、可读文字、标题和用户补充信息生成。
- 正文应准确概括共同主题，语言自然，不逐张机械罗列，不添加图片无法支持的事实。
- 多篇内容分别生成；一个手动正文只有在用户明确说明共用时才可复用。
- 平台没有独立标题框时，按对应workflow将标题作为正文首行一次；不得在正文中重复标题。
- 页面长度限制导致需要压缩时保留核心含义；无法可靠压缩时请求用户处理。
- 信息不足时返回`无法可靠生成图文“内容N”的正文，请补充主题或手动填写正文`。

统一审批摘要展示正文全文或足以核对的摘要，并明确标注`AI生成`或`手动输入`。
