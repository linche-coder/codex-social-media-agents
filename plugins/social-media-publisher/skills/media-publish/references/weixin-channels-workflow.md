# 视频号助手网页流程

已由用户提供真实页面截图确认官方发布页：`https://channels.weixin.qq.com/platform/post/create`。使用 Codex 自带浏览器实际进入并读取页面；若运行时被浏览器安全策略拦截，必须停止该平台并返回中文提示，不得绕过。

## 已确认的页面结构

- 视频上传区说明：时长 8 小时以内、大小不超过 20GB，建议 720P 及以上、码率 10Mbps 以内、MP4/H.264；仍以运行时页面提示为准。
- `视频描述`编辑区提供`#话题`和`@视频号`入口。
- 页面提供`短标题`、位置、合集、链接、活动、`定时发表`、`声明原创`、视频标注、保存草稿、手机预览和发表。
- 位置、合集、链接、活动和视频标注不是统一字段，保持页面默认值。

## 进入发布页

1. 优先复用 Codex 自带浏览器中已打开且可控制的视频号助手发布页。
2. 如果没有目标页，由自带浏览器打开官方发布入口并读取真实页面，不沿用旧版 Chrome 扩展的兼容性结论。
3. 若自带浏览器实际返回站点安全限制，将视频号标记为`浏览器安全策略阻止`并提示：`当前浏览器安全策略不允许 Agent 操作视频号助手页面。本次未上传、未提交发布，且不会尝试绕过；其他平台将继续。`
4. 登录过期、扫码、短信、验证码或安全验证必须由用户完成。
5. 页面可读后，先实际识别上传入口和全部可见字段；结构与本文件不符时停止，不猜测控件。

## 多视频页面预分配

多条视频任务必须在任务初始化阶段、任何视频上传前完成页面预分配：

1. 统计本次视频号视频数量`N`，一次性打开`N`个视频号发布页；已有可用空白发布页可以计入。
2. 逐页确认目标 URL、登录状态和空白上传区，按内容顺序建立`内容1 → 页面1`的固定映射。
3. 全部页面都创建并绑定成功后，才从页面1开始逐页串行上传和填写；不得并行操作文件选择器。
4. 页面准备完成后保持原标签页，不刷新、不关闭、不导航，也不在该页上传另一条视频。
5. 页面数量不足或任一页面不可控制时，不开始任何视频上传，返回`视频号需要 N 个上传页面，目前仅成功创建 M 个，尚未上传视频`。
6. 登录、安全验证或浏览器策略阻止初始化时，先按对应规则处理；恢复后重新核对全部页面池。

## 统一字段映射

- 视频：用户指定本地文件。
- 标题：用于生成`短标题`，不另造未确认的独立长标题控件。
- 简介：填入`视频描述`；若简介为空，视频描述保持为空。
- 标签：通过`#话题`入口形成有效话题，必须验证绑定状态。
- 封面：按 [cover-selection.md](cover-selection.md) 上传本地封面，或从视频候选帧中识别标题区域并选择标题完整清晰的画面。
- 发布时间：按 [schedule-policy.md](schedule-policy.md) 使用立即发布，或使用平台原生定时填写该内容对应的北京时间；不得擅自切换发布方式。

## 原创声明

`声明原创`是内部保留项，每条视频的默认目标都是勾选：

1. 进入编辑区后读取原创声明控件的可见选中状态。
2. 明确未勾选时使用`setChecked(true)`或等价的状态式操作。
3. 明确已勾选时不点击。
4. 状态不明确时重新读取控件属性、关联标签和选中标记；仍无法确定则返回`无法确认视频号原创声明状态，未发布`，不得反复盲点。

## AI 生成内容声明

完全忽略该项：不向用户展示、不读取、不判断、不修改，也不因为其状态改变其他操作。

## 自动短标题

短标题不向用户展示，只能根据该视频对应的原标题内容提炼演变：

1. 删除全部中英文标点和多余空白。
2. 若去标点后的原标题已满足页面长度限制且语义完整，直接使用。
3. 否则优先保留原标题的主语、核心对象、动作或判断，删除语气词、重复修饰和次要补充，使其成为原标题的自然短版。
4. 不改变原意，不照搬其他视频标题，不添加原标题没有的新主题，不制造夸张结论。
5. 根据页面当前字符计数或错误提示继续压缩，直到满足长度要求。
6. 无法在不改变原意的前提下满足限制时返回`无法生成符合视频号长度要求且不改变原意的短标题，未发布`。

示例：`农村盖房越来越贵，普通农民还盖得起吗？` → `农村盖房越来越贵`。

## 提交与结果

除原创声明和短标题外，位置、合集、链接、活动、视频标注等平台专用项保持默认。立即发布时选择或保留`不定时`并确认没有残留时间；定时发布时选择`定时`并用平台原生时间控件填写该内容对应的北京时间。提交前核对统一字段、原创声明、短标题、发布方式、目标时间（如有）和`发表`按钮。单平台在最终点击前请求自带浏览器动作前确认；多平台核对通过后标记为`等待统一发布确认`，不点击发表，等所有平台准备结束后统一确认并串行提交。

只有明确成功提示或作品管理中存在对应作品才能报告成功；结果不明确时返回`结果待确认，未自动重试`。

若页面仍不可取得控制权，保持`浏览器安全策略阻止`，不要无限重试。
