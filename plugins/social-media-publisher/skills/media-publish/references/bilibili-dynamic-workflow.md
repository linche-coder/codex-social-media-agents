# B站图文动态流程

目标产品为B站图文动态，使用动态发布入口，不进入视频投稿页。2026-09-04在Codex自带浏览器打开`https://t.bilibili.com/`时账号未登录，因此编辑控件、图片上限和定时能力尚未完成登录后验证。

1. 打开B站动态页并确认登录；未登录时请用户在当前自带浏览器完成登录并保留任务参数。
2. 登录后先读取真实动态发布区域，确认图片上传控件、图片上限、正文/标题结构、话题入口、发布方式和成功证据。
3. 多篇任务若一个页面不能保留多篇未发布动态，则在上传前创建独立标签页并绑定。
4. 一次上传当前内容项全部图片并核对数量与顺序。
5. 动态没有独立标题框时写入`标题 + 换行 + 正文`一次；存在独立标题框时分别填写。
6. 三条话题必须通过B站动态真实话题能力形成有效话题；不得使用视频投稿标签逻辑代替。
7. 不选择视频分区，不处理视频投稿创作声明。
8. 立即发布或原生定时能力必须以登录后真实页面为准；没有可验证定时能力时标记不支持，不模拟未来点击。
9. 准备完成后进入统一审批；发布结果不明确时不重复提交。
