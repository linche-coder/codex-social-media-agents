# 中文异常提示

先说明平台、问题和是否已提交发布，再给用户一个明确下一步。不要原样转发浏览器或网页的英文错误，不暴露内部工具名称、定位器或调试信息。

| 场景 | 中文提示模板 |
| --- | --- |
| 自带浏览器不可用 | `Codex 自带浏览器当前不可用。本次未上传、未提交发布，请重新打开任务后再试。` |
| 自带浏览器连接中断 | `Codex 自带浏览器连接已中断。已保留各平台页面状态摘要；重新进入任务后将按真实页面状态继续。` |
| 文件选择器未打开 | `平台名称没有打开可用的素材文件选择器。本次未重复上传，其他平台将继续。` |
| 页面预分配不足 | `平台名称需要 N 个上传页面，目前仅成功创建 M 个。尚未上传任何视频，请保留现有页面后重试。` |
| 平台登录过期 | `平台名称登录已过期或当前未登录，请在 Codex 自带浏览器的当前页面完成登录后回复“已登录”。已保留本次发布参数。` |
| 验证码/安全验证 | `平台名称要求验证码或安全验证，必须由你本人完成。完成后回复“验证完成”，我会从当前步骤继续。` |
| 批量范围无法解析 | `批量视频范围无法解析：原始输入。请使用同一目录、相同前缀、连续编号和相同扩展名，例如 F:\媒体\视频1.mp4 ～ 视频10.mp4。` |
| 批量范围缺少文件 | `批量视频范围中缺少以下文件：文件名列表。本次没有上传这些内容，请补齐文件或重新填写范围。` |
| 视频路径错误 | `找不到或无法读取视频文件：文件名。本次未上传、未提交发布，请检查本地绝对路径。` |
| 图片范围无法解析 | `图片范围无法解析：原始输入。请使用同一目录、相同前缀、连续编号和相同扩展名，例如 F:\图片\作品1\图片1.jpg ～ 图片6.jpg。` |
| 图片文件缺失 | `图文内容N缺少以下图片：文件名列表。本次未上传该篇图文，请补齐文件或重新填写。` |
| 图片数量超限 | `平台名称最多允许页面显示数量张图片，当前图文有实际数量张。没有静默删图或拆篇，请调整图片后重试。` |
| 图片格式/大小/比例不符 | `平台名称拒绝图片“文件名”：页面提示原因。本篇图文未提交。` |
| 图片上传状态不明确 | `平台名称图片上传状态待确认，未自动重试。为避免重复或乱序，已暂停该篇图文。` |
| 图片顺序不一致 | `平台名称页面图片顺序与用户输入不一致。本篇尚未提交，请保留页面检查。` |
| AI标题生成失败 | `无法可靠生成当前内容的标题，请补充主题或手动提供标题。本条/篇尚未上传或提交。` |
| AI正文生成失败 | `无法可靠生成图文“内容N”的正文，请补充主题或手动填写正文。本篇尚未提交。` |
| 格式/时长/大小不符 | `平台名称拒绝该视频：页面提示原因。本次未提交发布，请更换符合页面要求的视频。` |
| 标签未生效 | `平台名称标签“标签名”没有形成有效话题/标签，已停止该条内容。普通文本不计为成功标签。` |
| 标题封面识别失败 | `平台名称无法从候选画面中确认标题完整可见的封面。本次未随机选择，请在当前页面手动选择封面后继续。` |
| 本地封面失败 | `平台名称本地封面上传或裁剪失败。本次未提交发布，请检查封面文件后重试。` |
| 图文封面失败 | `平台名称无法确认指定图片已成为封面或首图。本篇尚未提交，没有擅自改变其他图片顺序。` |
| 平台不支持定时 | `平台名称当前页面不支持可验证的平台原生定时发布。本次没有改成立即发布。` |
| 定时时间无效 | `平台名称不接受计划时间：页面提示原因。没有改成立即发布，本次未提交。` |
| 发布按钮不可用 | `平台名称发布按钮当前不可用。已检查统一字段和发布方式，页面仍显示：可见原因。本次未提交。` |
| 页面结构变化 | `平台名称发布页结构可能已变化，无法定位“控件名称”。本次未提交发布，需要更新平台流程。` |
| 未找到真实素材input | `平台名称没有找到可确认的素材上传控件。本次未上传、未提交发布。` |
| 多平台文件注入未成功 | `平台名称已找到视频上传控件，但本次自带浏览器会话没有完成文件注入。已停止重复尝试；其他平台将继续。` |
| 文件注入状态待确认 | `平台名称文件注入状态待确认，未自动重试。为避免重复上传，已暂停该平台。` |
| 单次操作超时且已确认成功 | `平台名称“动作名称”响应超时，但页面已确认操作成功，将从下一步继续。` |
| 单次操作超时且明确未发生 | `平台名称“动作名称”响应超时，页面已确认操作未发生，将按规则最多重试一次。` |
| 操作状态无法确认 | `平台名称状态待确认，未自动重试。为避免重复上传、覆盖或提交，已暂停该平台，其他平台将继续。` |
| B站分区失败 | `无法根据标题、简介和标签确定唯一合适的B站分区，需要人工确认。本次尚未提交。` |
| B站创作声明缺失 | `B站要求选择创作声明，该项可能构成事实陈述，不能自动代选。请在当前页面完成选择后继续。` |
| 百家号创作声明缺失 | `百家号没有找到或无法确认“个人观点，仅供参考”创作声明。本条尚未提交，没有选择其他相近选项。` |
| 快手作者声明必填 | `快手当前页面要求填写作者声明；本工具不会代选。请在当前页面处理后继续。` |
| 微博权属项缺失 | `微博要求选择“类型”和/或“内容声明”，这些选项属于作品权属事实，不能自动代选。请在当前视频发布页完成选择后继续。` |
| 微博标题过长 | `微博视频标题超过页面允许的30字，没有自动截断或改写。本次未提交，请提供30字以内的标题。` |
| B站图文未登录 | `B站当前未登录，无法验证图文动态发布控件。请在Codex自带浏览器完成登录后回复“已登录”。` |
| 微博图文未登录 | `微博当前未登录，无法验证图片发布控件。请在Codex自带浏览器完成登录后回复“已登录”。` |
| 视频号图文受阻 | `当前浏览器安全策略不允许 Agent 操作视频号图文页面。本次未上传、未提交发布；其他平台将继续。` |
| 百家号图文受阻 | `当前浏览器安全策略不允许 Agent 操作百家号图文文章页面。本次未上传、未提交发布；其他平台将继续。` |
| 站点安全限制 | `当前浏览器安全策略不允许 Agent 操作平台名称页面。本次未上传、未提交，且不会尝试绕过；其他平台将继续。` |
| 发布失败 | `平台名称发布失败：页面提示原因。未自动重试。` |
| 发布结果不明确 | `平台名称结果待确认，未自动重试。为避免重复作品，没有再次点击发布。` |

页面有更具体的中文错误时，保留关键事实并套入上述结构。未知内部异常统一为：`平台名称操作失败，未提交发布。页面状态无法可靠判断，请保留当前页面以便检查。`

不要因为一次或连续数次 timeout 直接结束整个任务。先检查连接、原标签页和上一步页面后置状态，并继续其他可执行平台。只有确认自带浏览器整体不可用时才提示重新进入任务，且提示前先逐项列出平台状态。
