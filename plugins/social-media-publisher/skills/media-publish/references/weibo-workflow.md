# 微博网页版视频发布流程

官方网页入口使用`https://weibo.com/`，创作者中心入口为`https://me.weibo.com`。已通过登录账号实际确认：微博首页快捷发布器提供正文、视频、话题、定时微博、可见范围和发送；选择视频后会进入独立的`视频发布`页面。

实际上传完成后的页面包含：上传状态、必填`类型`、必填`内容声明`、0～30 字标题、视频抽帧封面/上传封面/裁剪封面、分类、合集、关联原视频、划重点、允许他人划重点、允许他人剪辑、微博内容、话题、地点、可见范围、定时入口和发布按钮。

## 进入发布页

1. 复用已登录的微博网页；没有时直接打开官方网页入口。
2. 页面出现`登录/注册`时提示：`微博登录已过期或当前未登录，请在 Codex 自带浏览器的当前页面完成微博登录后回复“已登录”。`保留全部任务参数。
3. 登录后按 [file-injection.md](file-injection.md) 等待首页快捷发布器顶层页面出现`input[type="file"][accept*="video"]`。该 input 同时接受图片和视频且当前为隐藏状态，不在 iframe 中。微博成为当前活动平台后，从此步骤到提交前核对完成都不操作其他平台。
4. 按 [file-injection.md](file-injection.md) 用自带浏览器把视频交给真实 input；若隐藏 input 不能产生 chooser 且页面明确为空，备用策略只点击首页发布器工具栏内的`视频`入口一次，必须排除顶部导航和内容筛选中的同名文字。完成上传、平台必需处理和全部字段准备前不切换其他平台。
5. 恢复时先识别快捷发布器、上传进度和独立`视频发布`页；已出现目标视频、上传进度或`上传完成`时不得重新选择文件。上传完成后确认已经进入标题上方显示`上传完成`的`视频发布`页面，再填写字段。

## 字段映射

- 视频：用户指定本地文件。
- 标题：原样填入独立`标题`输入框；页面当前限制为 0～30 字。超限时停止并提示用户修改，不擅自截断。
- 简介：原样填入`设置微博内容`文本框。
- 标签：优先使用页面真实话题或标签能力；逐字触发候选并验证已形成可识别话题链接、标签卡片或独立已选项。普通`#文字#`未被页面识别时不算成功。
- 封面：按 [cover-selection.md](cover-selection.md) 上传本地封面并保留标题区域，或在页面抽帧候选中识别标题区域并选择标题完整清晰的画面。
- 发布时间：按 [schedule-policy.md](schedule-policy.md) 设置。立即发布时保留普通发布并确认没有残留定时；定时发布时使用页面底部定时入口，填写该内容对应的北京时间并核对。

## 页面必填权属项

`类型`（原创/二创）和`内容声明`在真实页面中带星号且没有可靠默认值。二者属于作品权属事实，不能通过标题、简介或标签推断，也不能为了自动发布随意选择：

1. 先读取当前页面状态；已有明确选项时保持，不重复点击。
2. 任一项为空时，用中文一次性列出缺失项，请用户在当前页面选择后继续；不把它们加入统一任务表单。
3. 用户完成选择后重新识别状态；仍为空则停止发布。

分类、合集、关联原视频、划重点、允许他人划重点、允许他人剪辑、地点等不向用户展示，不主动修改，保持页面当前默认值。

## 提交与结果

提交前核对账号、上传完成状态、类型、内容声明、标题、微博内容、有效话题/标签、封面、发布方式与目标时间（如有）、错误和发布按钮。单平台在最终点击前请求自带浏览器动作前确认；多平台核对通过后标记为`等待统一发布确认`，不点击发布，等所有平台准备结束后统一确认并串行提交。

只有明确发布成功提示，或个人主页/内容管理中找到正文、视频和时间相符的微博，才能报告成功。结果不明确时返回`结果待确认，未自动重试`。

## 页面变化

如果登录后仍无法找到视频发布入口或必要字段，返回`微博发布页结构可能已变化，无法定位“控件名称”，未发布`。不得依据旧版公告猜测控件，也不得使用频道或分类代替用户未提供的统一字段。

上传、字段填写、封面、时间或发布发生 timeout 时，按 [execution-state.md](execution-state.md) 先验证页面后置状态，还要检查混合 input 的`files`和是否进入独立视频发布页；页面与 input 都明确为空时才可使用发布器`视频`入口作为第二种策略。两种策略都未获得 chooser 时返回`微博本次多平台会话未能完成文件注入`，暂停微博后再继续下一平台；不得据此判定永久不兼容。上传或发布状态不明确时禁止重复执行。
