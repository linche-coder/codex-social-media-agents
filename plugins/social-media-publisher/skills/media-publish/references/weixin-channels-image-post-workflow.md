# 视频号图文流程

目标产品为视频号图文，不套用视频发布页。2026-09-04使用Codex自带浏览器直接访问图文创建页时，被浏览器站点安全策略阻止，因此当前没有可靠的已验证控件结构。

1. 运行时只尝试平台公开的正常图文入口；若浏览器继续阻止，立即标记`浏览器安全策略阻止`并提示`当前浏览器安全策略不允许 Agent 操作视频号图文页面`。
2. 不切换到外部Chrome、Chrome扩展、CDP或其他方式绕过安全限制。
3. 页面未来可访问时，先完整读取并确认登录、图文入口、图片控件、数量限制、标题/正文/话题、封面、立即/定时和成功证据，再执行上传。
4. 不把视频页的短标题、声明原创或AI生成内容声明规则自动套用到图文；只有真实图文页面明确存在且用户规则允许时才处理。
5. 未完成页面验证前不得声称支持图文定时或已准备完成。

该平台被阻止时只暂停视频号，其他平台继续。
