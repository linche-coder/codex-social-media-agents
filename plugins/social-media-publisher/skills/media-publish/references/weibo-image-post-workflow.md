# 微博图片发布流程

目标产品为图片微博。2026-09-04在Codex自带浏览器打开`https://weibo.com/`时账号未登录，因此登录后的图片发布器、图片上限和定时能力尚未完成验证。

1. 打开微博首页并确认登录；未登录时请用户在当前自带浏览器完成登录。
2. 登录后读取首页发布器，只使用发布器内真实图片入口，排除导航、筛选和内容区中的同名控件。
3. 多篇任务若一个发布器不能保留多篇未发布微博，则在上传前创建独立标签页并绑定。
4. 一次上传当前内容项全部图片，核对缩略图数量和顺序。
5. 页面没有独立标题框时写入`标题 + 换行 + 正文`一次；存在独立标题框时分别填写。
6. 三条话题必须形成可点击或已绑定的完整微博话题，普通`#文字`不算成功。
7. 默认首图为封面；微博没有独立封面能力时按首图规则处理。
8. 立即或定时能力以登录后页面为准。无法验证原生定时时不得模拟未来发布。
9. 准备完成后进入统一审批；只有页面成功提示或个人主页/内容管理存在对应微博时报告成功。
