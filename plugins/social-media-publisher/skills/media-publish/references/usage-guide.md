# 社媒自动发布Agent使用说明

## 能做什么

通过Codex自带浏览器，将本地视频或图片发布到抖音、快手、小红书、视频号、B站、百家号和微博。支持单条、批量、立即发布和平台原生定时发布。所有可处理页面准备完成后，只进行一次统一发布审批。

## 使用前准备

1. 在Codex中使用`$media-publish`。
2. 在Codex自带浏览器登录需要使用的平台；不要只登录外部Chrome。
3. 准备本地绝对路径。工具不保存账号密码，也不复制素材。

## 可直接复制的填写模板

请复制以下内容，在对应字段后填写信息。未填写标题、正文/简介和话题时，默认由AI生成。

**发布平台：**  
（填写：抖音、快手、小红书、B站、微博、视频号或百家号。建议一次任务选择一个平台。）

**内容类型：**  
（填写：视频或图文。）

**视频：**  
（视频模式填写。支持上传文件、单个路径或批量范围，例如：`F:\媒体\视频1.mp4 ～ 视频10.mp4`。）

**图片：**  
（图文模式填写。多张图片组成一篇图文，例如：`F:\图片\作品1\图片1.jpg ～ 图片6.jpg`。）

**标题：**  
（可手动填写；留空或填写“AI生成”时，默认由AI根据素材生成。）

**正文 / 简介：**  
（图文对应正文，视频对应简介；可手动填写，默认AI生成。）

**话题：**  
（可手动填写；留空或填写“AI生成”时，默认生成3条相关话题。）

**封面：**  
（视频可填写本地封面路径或“AI推荐”；图文默认第1张，也可以填写“第3张”。）

**发布方式：**  
（填写：立即发布或定时发布。）

**定时时间：**  
（仅定时发布时填写，支持添加多个时间；时间数量应与内容数量一致。）

**其他要求：**  
（没有可以留空。平台特殊字段将在需要时单独提示。）

## 视频示例

```text
使用 $media-publish 发布视频。
发布平台：抖音、快手
内容类型：视频
视频：F:\媒体\视频1.mp4 ～ 视频10.mp4
标题：AI生成
简介：AI生成
话题：AI生成
封面：自动识别标题区域
发布方式：定时发布
开始日期：2026-09-10
每日时间：08:00、12:00、15:00、17:30
```

## 单篇图文示例

```text
使用 $media-publish 发布图文。
发布平台：抖音、快手、小红书、微博
内容类型：图文
图片：F:\图片\作品1\图片1.jpg ～ 图片6.jpg
标题：AI生成
正文：AI生成
话题：AI生成
封面：第1张
发布方式：立即发布
```

## 多篇图文示例

```text
使用 $media-publish 发布图文。
发布平台：小红书、微博
内容类型：图文
发布方式：定时发布
发布时间：
1. 2026-09-10 08:00
2. 2026-09-10 12:00

内容1：
图片：F:\图片\作品1\图片1.jpg ～ 图片6.jpg
标题：AI生成
正文：AI生成
话题：AI生成
封面：第1张

内容2：
图片：F:\图片\作品2\图片1.jpg ～ 图片4.jpg
标题：手动标题
正文：手动正文
话题：农村生活、乡村建设、真实记录
封面：第3张
```

## 注意事项

- 一组多张图片是一篇图文；多篇必须使用`内容1、内容2`分组。
- 标题、正文和三条话题可手填，留空默认AI生成。
- 平台图片数量或定时能力不同；工具不会静默删图或把定时改成立即发布。
- 验证码、登录、安全确认、删除旧内容和最终对外发布可能需要用户确认或接管。
- 上传成功不代表发布成功；只有页面明确成功或内容管理存在对应作品才算成功。
