# Codex 自带浏览器准备

本插件只使用 Codex 自带浏览器，不安装或调用 ChatGPT Chrome 扩展，也不切换到用户外部 Chrome、Edge 或其他浏览器。

## 启动

1. 使用 Browser Skill 明确选择`iab`，首次交互前完整读取该浏览器文档。
2. 上传本地文件前读取自带浏览器的`file-uploads`说明。
3. 为当前平台创建普通网页标签页并打开平台官方创作者后台；不要求用户预先打开页面。
4. 自带浏览器不可用或无法创建标签页时，提示：`Codex 自带浏览器当前不可用，本次未上传、未提交发布。请重新打开任务后再试。`不得回退到 Chrome 扩展。

## 登录

- 自带浏览器与用户日常 Chrome 的登录状态可能不同。
- 页面要求登录、扫码、验证码或安全验证时，保持当前标签页并交给用户完成。
- 等待用户操作或最终统一确认前，将相关标签页标记为后续可恢复；恢复后以页面真实状态继续。
- 不读取 Cookie、密码、Local Storage、Token 或浏览历史。

## 本地文件

通过页面原生文件选择器上传：先等待`filechooser`，再点击真实`input[type=file]`或能打开该选择器的可见上传入口，最后使用绝对路径设置文件。不得寻找`locator.setInputFiles`，不得使用系统原生窗口、脚本伪造`FileList`或复制素材到中转目录。
