# Codex自带浏览器本地素材上传规则

本文件处理七个平台的视频、图文图片和视频封面上传，只使用Codex自带浏览器公开的文件选择器能力。

## 路径解析

1. 逐条绝对路径保持原样。
2. 连续范围必须满足同一目录、相同前缀、相同扩展名和连续数字编号。
3. 视频范围中的每个文件是一条独立内容；图文范围中的全部图片属于当前一个内容分组。
4. 展开后逐个验证文件存在且可读；列出缺失文件，不搜索替代素材，不复制到中转目录。
5. 不把`文件1 ～ 文件10`范围文本或通配符直接传给文件选择器。

## 标准上传流程

1. 当前平台和当前内容必须是唯一活动任务，禁止并行文件选择器。
2. 读取真实`input[type=file]`的`accept`、`multiple`和父级语义，排除字幕、封面或错误素材类型。
3. 点击前等待当前页面的`filechooser`事件，再点击能打开同一选择器的真实上传入口；不打开系统原生文件窗口。
4. 视频内容默认为当前页面选择一个视频绝对路径。图文内容应先确认chooser支持多选，再一次设置当前内容项的全部图片路径。
5. 不伪造`FileList`、change/drop事件或修改页面脚本。
6. 上传后读取页面后置状态：视频检查文件名、进度、预览或编辑区；图文检查缩略图数量、顺序、进度和编辑区。
7. 出现明确证据即视为素材已交给平台；即使控制动作timeout也不得立即重传。
8. 页面和input都明确为空时，最多换一个已验证入口重试一次。状态仍不明时停止该内容。

用户明确要求发布并指定普通素材路径时视为已授权向目标平台上传。素材包含敏感个人信息时仍须在上传前说明具体素材和平台并请求确认。

## 图文额外核对

- 选择前确认平台当前显示的张数、格式、大小和比例限制。
- 用户图片超过平台上限时停止该平台当前内容；不得静默删图或拆篇。
- 上传后核对缩略图数量与预期一致，并按用户顺序逐张核对。
- 少图、重复图、顺序不明或部分上传失败时，不继续填写或提交。
- 图文上传timeout但页面显示部分图片时，不重新上传整组；标记`图片上传状态待确认，未自动重试`。

## 已验证入口摘要

- 抖音图文：`https://creator.douyin.com/creator-micro/content/upload`中的`发布图文`。
- 快手图文：`https://cp.kuaishou.com/article/publish/video`中的`上传图文`。
- 小红书图文：`https://creator.xiaohongshu.com/publish/publish`中的`上传图文`。
- B站、微博登录后控件以及视频号、百家号受限页面必须运行时重新验证，不能猜测。

## 结果分类

- 找不到正确input：`未找到真实素材上传控件`。
- chooser未返回且页面仍为空：`Codex自带浏览器本次未能打开平台素材上传控件`。
- 视频状态不明：`文件上传状态待确认，未自动重试`。
- 图文状态不明：`图片上传状态待确认，未自动重试`。
- 出现明确上传证据：`素材上传已开始`。
- 平台明确拒绝：使用页面可见的格式、大小、数量或比例原因归类。
