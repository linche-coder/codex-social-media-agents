# 百家号图文文章流程

目标产品为百家号图文文章，不套用视频发布页。2026-09-04使用Codex自带浏览器直接访问图文编辑页时，被浏览器站点安全策略阻止，因此当前没有可靠的已验证控件结构。

1. 运行时只尝试百家号公开的正常图文文章入口；若浏览器继续阻止，标记`浏览器安全策略阻止`并继续其他平台。
2. 不通过外部Chrome、Chrome扩展、CDP或备用域名绕过安全限制。
3. 页面未来可访问时，先确认登录、文章标题、富文本正文、图片插入/上传、标签、封面、分类、创作声明、立即/定时和成功证据。
4. 图片按用户顺序插入文章；页面只支持逐张插入时仍须逐张核对位置，不把图片拆成多篇。
5. 图文文章页面存在可准确识别的创作声明时选择`个人观点，仅供参考`；没有该精确选项时停止，不选择相近项。
6. 分类仅在页面强制必填时根据标题、正文和图片建议；无法唯一判断时进入人工确认，不随意选择。
7. 原生定时能力未验证前不得声称支持；不支持时不改成立即发布。

被阻止时固定提示：`当前浏览器安全策略不允许 Agent 操作百家号图文文章页面。本次未上传、未提交发布；其他平台将继续。`
