# 视频标题区域识别与封面选择

本规则适用于所有平台。目标是让封面中的视频内嵌标题完整、清晰且不被裁切，不是重新生成标题或在封面上添加新文字。

## 用户提供本地封面

1. 优先上传用户指定图片。
2. 在平台横版、竖版或裁剪预览中识别已有标题区域。
3. 调整裁剪位置，使完整标题位于安全区域；不得裁掉标题首尾、上下行或关键人物主体。
4. 无法同时保留完整标题和平台要求画幅时停止该条，提示用户提供适配尺寸的封面，不擅自删字或拉伸。

## 从视频候选帧选择

1. 等待平台生成可见候选帧、时间轴缩略图或智能推荐画面。
2. 读取候选区域截图，比较各帧中标题文字的完整度、清晰度、对比度和安全边距。
3. 优先选择：标题全部出现、没有被人物或控件遮挡、距离裁剪边缘足够、主体清晰的画面。
4. 多个候选同样合适时，选择标题面积更大、人物表情更自然、画面更清晰的一帧。
5. 选择后读取封面预览，确认横竖裁剪没有截断标题；平台提供位置或裁剪控件时，移动到能完整保留标题的位置。
6. 不因`AI推荐`标签直接接受第一帧，也不随机选择。
7. 候选帧中没有完整标题，或截图不足以可靠识别时，返回`未找到标题完整可见的封面画面，需要人工选择`，不冒充成功。
