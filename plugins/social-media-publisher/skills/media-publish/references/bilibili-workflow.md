# B站创作中心视频投稿流程

已确认的视频投稿页：`https://member.bilibili.com/platform/upload/video/frame`。优先使用可见文字、标签、角色和控件状态定位，不依赖固定坐标。

## 已确认的进入与上传状态

- 登录后创作中心可见`投稿`和当前账号状态。
- 视频投稿页可见文件选择控件和`上传视频`区域。
- 当前页面说明普通视频 16GB 以内、10 小时以内，推荐 MP4/MOV/MKV，推荐 1080P/4K；具体限制仍以运行时页面为准。
- 上传后已确认页面提供：封面与`AI生成`、标题、必填创作声明、分区、标签、简介、定时发布、存草稿和立即投稿。
- 当前原生定时规则显示为距离当前最早不少于 5 分钟、最晚不超过 15 天；每次运行仍以页面规则为准。

## 执行流程

1. 复用视频投稿页；没有时直接打开已确认地址。
2. 从顶部账号状态判断登录。扫码、验证码和安全验证必须由用户完成。
3. 恢复时先识别是否存在未提交视频、上传进度或编辑区。检测到旧内容时标记 B站为`等待确认放弃旧内容`，保留现有安全规则；用户确认前不删除、不重新上传，但其他平台继续执行。
4. 空白上传页按 [file-injection.md](file-injection.md) 区分视频 input。B站成为当前活动平台后等待两个视频 input 完成渲染，先使用`.bcc-upload-wrapper`内接受`.mp4`的 input；页面与两个视频 input 都明确为空时，才尝试`input[name="buploader"][accept*=".mp4"]`一次。必须排除`accept=".txt"`字幕 input，不依赖动态父容器 ID。完成上传、平台必需处理和全部字段准备前不切换其他平台。
5. 编辑区已存在目标视频时跳过上传，重新识别标题、简介、标签、封面、分区、发布时间和提交按钮。
6. 标题原样填入稿件标题；简介原样填入稿件简介。
7. 标签通过 B站标签控件逐个添加，并验证每个标签已成为独立已选项；普通输入文字不算成功。
8. 按 [cover-selection.md](cover-selection.md) 设置封面：有本地封面时上传并保留标题区域；否则在抽帧或 AI 候选中识别标题区域，选择标题完整清晰的一帧。没有合格候选时请用户手动选择。
9. 按 [schedule-policy.md](schedule-policy.md) 设置发布方式：立即发布时选择或保留立即投稿并确认没有残留定时；定时发布时仅使用页面原生定时，填写该内容对应的北京时间并核对。页面无法支持用户指定方式时停止，不擅自切换。
10. 分区以外的非统一设置保持页面默认；商业推广、合集和更多设置不主动修改。

## 必填创作声明

实际页面将`创作声明`标为必填，但产品统一表单不新增该字段。处理规则：

1. 页面已有明确默认值时保持默认并在提交前核对。
2. 页面为空时不得自行选择`自制`、`转载`或其他可能构成事实陈述的项目。
3. 返回`B站要求选择创作声明，需要你在当前页面完成选择；统一任务信息已保留。`用户选择后继续，不把该项永久加入统一表单。

## 分区自动识别

分区不向用户展示为输入项。Agent 在上传后读取页面当前可选分区，并根据`标题 + 简介 + 标签`选择：

1. 将三项文本合并，仅用于本次语义判断，不保存。
2. 优先匹配内容主题明确、稳定、常见且页面当前存在的分区；不选择活动临时分区或仅凭单个模糊词匹配。
3. 标题与标签权重高于简介中的附带词；多个字段一致指向同一主题时才视为清晰。
4. 选择后读取控件回显，确认选中的分区文字与判断一致。
5. 如果两个候选同样合理、文本信息不足、页面候选与内容不匹配，或回显不明确，返回`无法根据标题、简介和标签确定唯一合适的B站分区，需要人工确认`，进入待人工确认状态，禁止随意乱选。

人工确认只询问用户选择分区，不把分区永久加入统一任务表单。

## 提交与结果

提交前核对账号、视频、标题、简介、B站标签、封面、创作声明、已确认分区、发布方式与目标时间（如有）、错误和最终投稿按钮状态。单平台在最终点击前请求自带浏览器动作前确认；多平台核对通过后标记为`等待统一发布确认`，不点击投稿，等所有平台准备结束后统一确认并串行提交。

只有明确投稿成功提示，或稿件管理中存在标题、状态和时间相符的稿件，才能报告成功。结果不明确时返回`结果待确认，未自动重试`。

## 页面变化

上传后找不到必要控件时返回`B站投稿页结构可能已变化，无法定位“控件名称”，未发布`，不得套用其他平台定位。

任一动作 timeout 时按 [execution-state.md](execution-state.md) 先检查后置状态，并检查两个视频 input 的`files`；二者均为空且页面仍是空白上传区时，才能切换一次 BUploader 备用 input。两种策略都未获得可设置文件的 chooser 时返回`B站本次多平台会话未能完成文件注入`，暂停B站后再继续下一平台；不得据此判定永久不兼容。放弃旧内容和最终投稿状态不明确时禁止重复执行。
