# 抖音图文作品流程

目标页：`https://creator.douyin.com/creator-micro/content/upload`，选择`发布图文`。2026-09-04在Codex自带浏览器实测该入口可用：最多35张；支持jpg、jpeg、png、webp，不支持gif；单个图片文件不超过50MB；不建议宽高比超过1:2，推荐3:4或4:3。每次运行仍以页面当前提示为准。

1. 打开目标页并确认登录、`发布图文`已选中和空白上传区。不得停留在`发布视频`。
2. 多篇任务在本平台上传前按内容数量创建独立发布标签页并固定绑定，每页只对应一篇图文。
3. 按 [file-injection.md](file-injection.md) 一次选择当前内容项的全部图片；上传后核对缩略图数量与顺序。
4. 图片数量、格式、大小或比例违反页面规则时停止当前内容，不静默删图。
5. 上传后读取一次真实编辑页，再将标题、正文和三条话题映射到可见控件。页面字段与预期不同则停止并报告，不复用视频页定位。
6. 三条话题必须形成平台认可的有效话题；普通`#文字`不算成功。
7. 默认首图为封面；页面有独立封面能力时按 [image-post-common.md](image-post-common.md) 设置。
8. 按 [schedule-policy.md](schedule-policy.md) 设置立即或平台原生定时发布，并核对回显。
9. 准备完成后保留页面并进入统一审批，不提前点击发布。

只有明确成功提示，或内容管理中存在标题、图片数量、状态和时间相符的作品，才能报告成功。结果不明时不得再次发布。
