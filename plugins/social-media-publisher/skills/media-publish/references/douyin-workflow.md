# 抖音创作者中心网页流程

目标页面：`https://creator.douyin.com/creator-micro/content/upload`。优先使用可见文字、标签、角色和控件状态定位，不依赖固定坐标。

## 进入发布页

1. 复用已打开的抖音发布页；没有时新建普通网页标签并直接打开目标地址。
2. 没有目标页时由 Codex 自带浏览器新建标签并导航到目标地址，不要求用户手动打开后台。
3. 从页面可见状态判断登录。扫码、短信、验证码或安全确认必须由用户完成。
4. 直接使用当前唯一登录账号，并记录页面可见账号供提交确认和结果汇报；不向用户索取账号字段。

## 多视频页面预分配

多条视频任务必须在任务初始化阶段、任何视频上传前完成页面预分配：

1. 统计本次抖音视频数量`N`，一次性打开`N`个抖音发布页；已有可用空白上传页可以计入。
2. 逐页确认目标 URL、登录状态和空白上传状态，按内容顺序建立`内容1 → 页面1`的固定映射。
3. 全部`N`个页面都创建并绑定成功后，才从页面1开始逐页串行上传。不得同时触发多个文件选择器。
4. 页面准备完成后保持原标签页，不刷新、不关闭、不导航，也不在该页上传另一条视频。
5. 页面数量不足或任一页面无法确认时，不开始任何视频上传，返回`抖音需要 N 个上传页面，目前仅成功创建 M 个，尚未上传视频`。
6. 登录或旧内容提示阻止初始化时，完成相应人工步骤后重新核对全部页面池，再开始上传。

## 上次未发布内容

用户的默认目标是`放弃旧内容`。出现“还有上次未发布的视频”“恢复上次内容”或同义弹窗时，放弃会删除未发布数据，必须在点击语义为`放弃`的按钮前请求动作前确认。用户确认后点击一次`放弃`，确认回到空白上传状态并继续本次任务；用户明确选择`恢复`时才恢复旧内容。

该授权只覆盖发布页自动恢复的临时内容。若页面表示将删除内容管理中的草稿、已发布作品或其他不可恢复内容，必须停止并说明。

## 快速执行

恢复或重新连接时按`内容项 → 标签页`映射逐页读取：若目标视频已存在、出现上传进度或已经进入视频编辑页，禁止重新选择文件，直接等待或从第一个未完成字段继续。只有绑定页面明确为空白上传状态且没有目标视频时，才为上传控件选择该内容对应的绝对路径。

1. 确认处于`作品发布 → 发布视频`，按上述恢复规则决定是否选择文件。
2. 文件选择成功后，页面允许时立即连续填写标题、简介映射的正文和发布时间，不空等后台处理。标签按下方专用流程映射为话题，不能作为普通正文批量填充。
3. 标题与简介原样填写。
4. 按 [cover-selection.md](cover-selection.md) 设置封面：有本地封面时上传并确保标题区域完整；否则识别候选视频帧中的标题区域，选择标题完整清晰的一帧并验证预览。
5. 内容声明和其他非统一字段保留页面当前默认值，不向用户索取或主动修改。
6. 按 [schedule-policy.md](schedule-policy.md) 设置发布方式：立即发布时确认定时设置关闭且无残留时间；定时发布时开启网页原生定时，填写该内容对应的北京时间并核对回显。
7. 上传和平台必需处理完成后统一核对一次。快速检测不是阻塞步骤；最终按钮可用且没有错误时不等待快速检测。

## 标签必须形成有效话题

对用户给出的每个标签依次执行：

1. 去除用户输入开头已有的`#`，保留话题名称和顺序。
2. 点击话题输入位置或正文中用于添加话题的位置。使用逐字键入触发页面事件，不使用一次性`fill`把`#话题名`当作普通文字写入。
3. 按页面交互输入`#`及话题名称，等待候选列表出现，点击文字准确匹配的候选项。
4. 点击候选后立即验证页面已出现独立的话题标签、话题卡片、可识别的话题链接或其他明确的已选中状态。编辑框中只有普通`#话题名`文字不算成功。
5. 若候选未出现或点击后未形成标签，清除本次未完成的普通文字，使用更慢的逐字输入重试一次。不得重复添加已经成功的话题。
6. 重试后仍失败，切换稳定模式并报告具体失败的话题；不得把普通文字误报为已添加话题，也不得带着缺失话题直接发布。

全部标签添加完成后，统一核对已形成的话题数量、文字和顺序与用户输入一致。

## 提交前内部核对

只核对影响结果的项目：

- 当前账号及用户指定的视频；
- 上传和平台必需处理已完成；
- 标题、简介映射的正文、有效话题和封面；
- 可见范围、发布时间、页面阻塞错误和最终按钮状态。

核对通过后：单平台在最终按钮可用时请求自带浏览器动作前确认；多平台将抖音标记为`等待统一发布确认`，不点击最终按钮，随后按队列准备下一个平台。所有平台准备结束后只请求一次统一确认；用户确认后再按平台顺序点击一次最终提交。若页面随后出现本次发布的原生确认框，可作为同一次已确认发布继续处理并等待结果。

## 结果验证

看到明确成功提示，或在内容管理中找到标题、状态和时间相符的作品，才能报告`已发布`或`已提交平台定时发布`。只有提交结果不明确时才进入内容管理核验；仍无法判断时报告`结果待确认，未自动重试`，不得再次点击提交。

格式、大小、时长、网络、验证码、风控或平台强制等待必须按页面处理，并用简明中文向用户说明。

选择文件、字段填写、封面、时间或提交发生 timeout 时，按 [execution-state.md](execution-state.md) 先验证页面后置状态。不得因为 timeout 重新上传；已进入编辑页即视为上传链路已发生，从当前编辑状态继续。
