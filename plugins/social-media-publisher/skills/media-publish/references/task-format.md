# 社媒发布任务格式

本文件用于内部解析和任务规范。首次向用户收集信息时必须读取并使用 [input-template.md](input-template.md)，不要把下面的内部字段表直接展示给用户。标题、图文正文和三条话题可手动输入或AI生成，留空默认AI生成；视频和图片均支持批量范围。

## 通用字段

| 字段 | 必需 | 说明 |
| --- | --- | --- |
| 发布平台 | 是 | 抖音、快手、小红书、视频号、B站、百家号、微博，可多选。 |
| 内容类型 | 是 | `视频`或`图文`；素材类型明确时可识别，不明确时询问。 |
| 发布方式 | 是 | `立即发布`或`定时发布`。 |
| 定时信息 | 条件必需 | 定时任务可逐条列出完整时间，或填写开始日期和每日多个时间。 |
| 标题 | 否 | 手动输入或AI生成，默认AI生成。 |
| 话题 | 否 | 手动输入或AI生成，默认每条/篇生成三条。 |
| 封面 | 否 | 视频可用本地图片或标题帧；图文默认首图，也可指定第N张。 |

视频专用字段：`视频、简介`。图文专用字段：`图片、正文`。不向用户索取账号、非必要分类和其他平台专属字段。

## 视频批量

```text
视频：F:\媒体\视频1.mp4 ～ 视频10.mp4
```

表示十条独立视频内容。逐个展开、验证并按编号顺序处理。

## 单篇多图

```text
图片：F:\图片\作品1\图片1.jpg ～ 图片6.jpg
```

表示六张图片组成一篇图文。不得自动拆成六篇。

## 多篇图文

```text
内容1：
图片：F:\图片\作品1\图片1.jpg ～ 图片6.jpg
标题：AI生成
正文：AI生成
话题：AI生成
封面：第1张

内容2：
图片：
- F:\图片\作品2\封面.jpg
- F:\图片\作品2\细节1.jpg
- F:\图片\作品2\细节2.jpg
标题：手动标题
正文：手动正文
话题：话题一、话题二、话题三
封面：第1张
```

每个内容分组是一篇图文。多组标题、正文、话题、封面和时间按内容顺序一一对应；只有用户明确说明共用时才复用单个值。

## 立即发布模板

```text
使用 $media-publish 发布图文。
发布平台：抖音、快手、小红书、微博
内容类型：图文
图片：F:\图片\作品1\图片1.jpg ～ 图片6.jpg
标题：AI生成
正文：AI生成
话题：AI生成
封面：第1张
发布方式：立即发布
```

## 多时间定时模板

```text
使用 $media-publish 发布图文。
发布平台：小红书、微博
内容类型：图文
发布方式：定时发布
开始日期：2026-09-10
每日时间：08:00、12:00、15:00、17:30

内容1：
图片：F:\图片\作品1\图片1.jpg ～ 图片6.jpg
标题：AI生成
正文：AI生成
话题：AI生成

内容2：
图片：F:\图片\作品2\图片1.jpg ～ 图片4.jpg
标题：AI生成
正文：AI生成
话题：AI生成
```

也可用`发布时间`逐条提供与内容数量相同的完整北京时间。详细规则见 [schedule-policy.md](schedule-policy.md)。

## 图文平台映射

| 平台 | 图文产品 | 标题/正文 | 话题 | 封面 | 发布时间 |
| --- | --- | --- | --- | --- | --- |
| 抖音 | 图文作品 | 运行时映射真实标题和正文控件 | 有效话题 | 首图或独立封面 | 立即/原生定时 |
| 快手 | 图文作品 | 无独立标题时合并到作品描述 | 有效话题 | 首图或独立封面 | 立即/原生定时 |
| 小红书 | 图文笔记 | 笔记标题和正文 | 有效话题 | 首图或指定图 | 立即/原生定时 |
| 视频号 | 视频号图文 | 必须先通过真实页面验证 | 有效话题 | 以真实页面为准 | 以真实页面为准 |
| B站 | 图文动态 | 无标题框时标题作为正文首行 | 动态话题 | 首图 | 以真实页面为准 |
| 百家号 | 图文文章 | 文章标题和富文本正文 | 标签/话题 | 以真实页面为准 | 以真实页面为准 |
| 微博 | 图片微博 | 无标题框时标题作为正文首行 | 微博话题 | 首图 | 以真实页面为准 |

## 统一审批摘要

逐平台逐内容展示：内容类型、视频文件或图片数量与顺序、标题、正文/简介、三条话题、封面、发布方式、目标时间、页面警告和最终按钮状态。只有全部可处理内容准备完成后才请求一次最终审批。
