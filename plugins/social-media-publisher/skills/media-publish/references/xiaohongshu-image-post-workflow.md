# 小红书图文笔记流程

目标页：`https://creator.xiaohongshu.com/publish/publish`，选择`上传图文`。2026-09-04在Codex自带浏览器实测该入口可用：单个图片最大32MB；推荐png、jpg、jpeg、webp，不支持gif、live及其转换图片；建议比例3:4至2:1，分辨率不低于720×960。入口未显示固定张数上限，运行时以页面实际限制为准。

1. 打开目标页并选择`上传图文`，确认登录和空白上传区；不要使用`文字配图`代替用户图片。
2. 多篇任务如果一个页面不能保留多篇未发布笔记，则在本平台上传前按内容数量创建独立标签页并固定绑定。
3. 按 [file-injection.md](file-injection.md) 一次选择当前内容项全部图片，核对数量、顺序和上传状态。
4. 上传后读取真实编辑页，填写笔记标题和正文。
5. 通过真实`话题`入口逐条输入完整话题并选择精确匹配候选；三条均须形成有效话题。
6. 默认首图为封面；用户指定其他图片时使用页面封面/排序能力，并核对最终首图或封面。
7. 附加设置保持页面默认，不使用活动或AI改写替代用户任务。
8. 按 [schedule-policy.md](schedule-policy.md) 设置立即或平台原生定时发布并核对。
9. 准备完成后保留页面进入统一审批。

只有明确成功提示或笔记管理中存在标题、图片、状态和时间相符的笔记，才能报告成功。
