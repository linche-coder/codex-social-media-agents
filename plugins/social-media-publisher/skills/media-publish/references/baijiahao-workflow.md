# 百家号视频发布网页流程

已由用户提供真实页面截图确认官方视频编辑页：`https://baijiahao.baidu.com/builder/rc/edit?type=videoV2&is_from_cms=1`。使用 Codex 自带浏览器实际进入并读取页面；若运行时被浏览器安全策略拦截，必须停止该平台并返回中文提示，不得绕过。

## 已确认的页面结构

- 页面提供横竖封面预览和`智能推荐封面`。
- 页面使用一个`作品描述`编辑区，提示填写作品标题并添加话题，当前显示 50 字计数和`#话题`入口。
- 页面提供活动投稿、转载、地点、水印、IP版权、创作声明等附加项，以及`存草稿`、`定时发布`和`发布`按钮。
- 截图中没有用户需要填写的分类字段。

## 进入发布页

1. 优先复用 Codex 自带浏览器中已打开且可控制的百家号视频发布页。
2. 没有目标页时由自带浏览器进入已确认的官方视频编辑页，不沿用旧版 Chrome 扩展的兼容性结论。
3. 若自带浏览器实际返回站点安全限制，将百家号标记为`浏览器安全策略阻止`并提示：`当前浏览器安全策略不允许 Agent 操作百家号创作后台。本次未上传、未提交发布，且不会尝试绕过；其他平台将继续。`
4. 登录过期、短信、扫码、验证码或安全验证必须由用户完成。
5. 页面可读后实际识别上传、标题、简介、标签、封面、发布时间和发布按钮；无法确认时停止。

## 多视频页面预分配

多条视频任务必须在任务初始化阶段、任何视频上传前完成页面预分配：

1. 统计本次百家号视频数量`N`，一次性打开`N`个百家号视频发布页；已有可用空白发布页可以计入。
2. 逐页确认目标 URL、登录状态和空白上传区，按内容顺序建立`内容1 → 页面1`的固定映射。
3. 全部页面都创建并绑定成功后，才从页面1开始逐页串行上传和填写；不得并行操作文件选择器。
4. 页面准备完成后保持原标签页，不刷新、不关闭、不导航，也不在该页上传另一条视频。
5. 页面数量不足或任一页面无法确认时，不开始任何视频上传，返回`百家号需要 N 个上传页面，目前仅成功创建 M 个，尚未上传视频`。
6. 登录、安全验证或浏览器策略阻止初始化时，先按对应规则处理；恢复后重新核对全部页面池。

## 字段映射

- 视频：用户指定本地文件。
- 标题：填入已确认的`作品描述`编辑区首行。
- 简介：标题后换行追加到`作品描述`；若页面 50 字限制无法容纳完整标题和简介，保留完整标题并提示简介未能完整映射，不擅自改写。
- 标签：通过作品描述中的`#话题`入口添加，必须验证已形成独立有效话题。
- 封面：按 [cover-selection.md](cover-selection.md) 上传本地封面，或在智能推荐候选中识别标题区域并选择标题完整清晰的画面。
- 发布时间：按 [schedule-policy.md](schedule-policy.md) 使用立即发布，或使用平台原生定时填写该内容对应的北京时间；不得擅自切换发布方式。

## 分类和附加项

- 分类不向用户展示、不要求用户填写，也不主动修改页面当前默认值。
- `创作声明`不向用户展示为输入字段。每条视频选择`个人观点，仅供参考`：先读取当前值，已选中时不重复操作；未选中时打开创作声明并选择文字完全一致的选项，然后核对回显。找不到该选项或回显不明确时停止该条，不选择相近选项。
- 活动投稿、转载、地点、水印、IP版权和其他额外配置都不展示、不主动修改，保持页面当前默认值。
- 如果页面将分类变为阻止发布的必填项且没有默认值，返回`百家号当前页面要求选择分类，与本工具的统一字段方案冲突，需要人工处理`，不得随意选择。

## 提交与结果

提交前核对统一字段、创作声明回显为`个人观点，仅供参考`、发布方式与目标时间（如有）、页面错误和发布按钮状态。单平台在最终点击前请求自带浏览器动作前确认；多平台核对通过后标记为`等待统一发布确认`，不点击发布，等所有平台准备结束后统一确认并串行提交。

只有明确成功提示或内容管理中存在对应作品才能报告成功。结果不明确时返回`结果待确认，未自动重试`。

若页面仍不可取得控制权，保持`浏览器安全策略阻止`，不要无限重试。
