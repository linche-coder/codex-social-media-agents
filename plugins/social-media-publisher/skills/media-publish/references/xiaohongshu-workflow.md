# 小红书创作服务平台网页流程

已确认的视频发布页：`https://creator.xiaohongshu.com/publish/publish?target=video`。页面当前也可能附带`from`或`openFilePicker`参数；定位时只依赖页面可见结构，不依赖完整查询字符串或固定坐标。

## 已确认的进入与上传状态

- 登录后首页可见`发布笔记`、`发布视频笔记`和当前账号信息。
- 视频发布页可见`上传视频`、文件选择控件和拖拽区域。
- 当前页面说明支持常用视频格式，推荐 MP4/MOV，时长 4 小时以内、最大 20GB。
- 上传后已确认页面提供：`填写标题会有更多赞哦`标题框、正文编辑区、`话题`按钮、`智能推荐封面`、`重新生成`、`应用`、`定时发布`开关和公开可见状态。
- 页面还会展示推荐话题、内容声明、合集、地点、活动等附加项；除统一字段外不主动修改。

## 执行流程

1. 复用已打开的小红书视频发布页；没有时直接打开目标地址。
2. 从页面可见账号和发布区域判断登录状态。登录过期、扫码、短信、验证码或安全验证必须交给用户。
3. 恢复时先识别目标视频、上传进度和编辑区；目标视频存在、正在上传或编辑区已就绪时跳过文件选择。只有页面明确为空白上传状态时才为文件控件选择用户指定的视频。上传后等待编辑区域出现，再按可见标签重新识别控件。
4. 标题填入笔记标题；简介原样填入笔记正文。
5. 按 [cover-selection.md](cover-selection.md) 设置封面：有本地封面时上传并确保标题区域完整；否则在`智能推荐封面`候选中识别标题区域，选择标题完整清晰的一帧，点击`应用`并验证预览。没有合格候选时可`重新生成`一次；仍无合格画面则请用户手动选择。
6. 按 [schedule-policy.md](schedule-policy.md) 设置发布方式：立即发布时确认`定时发布`关闭且无残留时间；定时发布时开启开关，使用平台原生时间控件填写该内容对应的北京时间并核对回显。
7. 除统一字段外，其他设置保持页面默认值。

## 标签必须形成有效话题

对每个用户标签依次处理：

1. 去掉开头已有的`#`，保留名称和顺序。
2. 使用页面的话题入口或正文中的话题交互，逐字输入以触发候选。
3. 选择文字准确匹配的候选项。
4. 立即验证出现独立话题标签、话题卡片、链接或其他明确绑定状态。正文中只有普通`#文字`不算成功。
5. 候选未出现或未绑定时清除本次普通文字，用更慢的逐字输入重试一次；仍失败则返回`小红书标签“名称”未形成有效话题，未发布`。

## 提交与结果

提交前核对账号、视频、标题、正文、有效话题、封面、发布方式与目标时间（如有）、页面错误和发布按钮状态。单平台在最终点击发布前请求自带浏览器动作前确认；多平台核对通过后标记为`等待统一发布确认`，不点击发布，等所有平台准备结束后统一确认并串行提交。

只有明确成功提示，或在笔记管理中找到标题、状态和时间相符的笔记，才能报告成功。结果不明时返回`结果待确认，未自动重试`。

## 页面变化

上传后若无法找到标题、正文、话题、封面、发布时间或发布按钮，返回`小红书发布页结构可能已变化，无法定位“控件名称”，未发布`。不得用固定坐标或复用抖音定位。

选择文件或其他可能改变页面状态的动作发生 timeout 时，按 [execution-state.md](execution-state.md) 先验证后置状态；上传状态不明确时禁止重复选择文件。
