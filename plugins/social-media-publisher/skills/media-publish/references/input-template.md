# 用户填写模板

用户尚未提供完整任务、询问如何填写或需要补充字段时，只输出下面这份可复制模板。不要先展示字段表格，不要逐个平台罗列规则，不要附加大段解释。当前产品支持writing block时，将整份模板放入一个`standard` writing block，并为当前对话生成新的五位数ID，使用户可以一键复制；不支持时直接输出模板正文。

字段名必须使用Markdown加粗。括号中的说明保持简短。用户已经填写的内容应带入模板；不要要求用户重复提供已有信息。标题、正文/简介和话题留空或填写`AI生成`时按AI生成处理，用户手动内容优先。

---

请复制以下内容，在对应字段后填写信息。未填写标题、正文/简介和话题时，默认由AI生成。

**发布平台：**  
（填写：抖音、快手、小红书、B站、微博、视频号或百家号。建议一次任务选择一个平台。）

**内容类型：**  
（填写：视频或图文。）

**视频：**  
（视频模式填写。支持上传文件、单个路径或批量范围，例如：`F:\媒体\视频1.mp4 ～ 视频10.mp4`。）

**图片：**  
（图文模式填写。多张图片组成一篇图文，例如：`F:\图片\作品1\图片1.jpg ～ 图片6.jpg`。）

**标题：**  
（可手动填写；留空或填写“AI生成”时，默认由AI根据素材生成。）

**正文 / 简介：**  
（图文对应正文，视频对应简介；可手动填写，默认AI生成。）

**话题：**  
（可手动填写；留空或填写“AI生成”时，默认生成3条相关话题。）

**封面：**  
（视频可填写本地封面路径或“AI推荐”；图文默认第1张，也可以填写“第3张”。）

**发布方式：**  
（填写：立即发布或定时发布。）

**定时时间：**  
（仅定时发布时填写，支持添加多个时间；时间数量应与内容数量一致。）

示例：
- 2026-09-05 10:00
- 2026-09-05 18:00
- 2026-09-06 12:00

**其他要求：**  
（没有可以留空。平台特殊字段将在需要时单独提示。）

---

用户回填后直接解析任务。只有真正缺失且无法从上下文推断的信息才再次询问；不要再次完整重复模板。
